{"summary": "这次聊天的摘要，不超过 200 字，保留具体的事", "gist": "一句话，像日记里的一行", "importance": 1到10的整数, "valence": -1到1的小数, "notes": [{"text": "一句话，第三人称'他'，带日期", "kind": "fact / event / howto / insight / self 之一", "about": "路过 / 日常 / 本人 / 一辈子 之一", "arousal": 0到1, "valence": -1到1, "tags": ["关键词"]}], "followups": [{"text": "要问他的事", "due": "YYYY-MM-DD"}], "pact_done": [{"id": 约定的编号, "state": "kept 或 dropped"}]}

- notes 只补聊天里值得记但还没记下的；"已记下的"和"你一直记得的"里有的不要重复。关于聊天本身的事（他在考你记性、问你记不记得）不记。没有就 []。
- **先逐句过一遍他说的话，这一步别省**：他说到自己的身份（名字、学校、专业、年级）、家人、家乡、住哪、身体（过敏、生病）、长期的喜好、对你的承诺、你答应他的事（写成"我答应他……"）、他给你起的外号（写成"他给我起的外号是 X"），而"已记下的"和"你一直记得的"里都没有的，每样补一条（about 填 本人 或 一辈子）。聊天时漏记的，这是最后补上的机会。
- importance 是这次聊天整体有多重要（1–10）。每条 note 的 about：路过 = 一顿饭、正在干嘛；日常 = 近况、计划、一次性的事；本人 = 他长期不变的事（学校、家人、长期喜好；这几天的状态不算）；一辈子 = 生日、纪念日、名字和外号、他答应你的、你答应他的、你们说好的事（听着像计划也算）。arousal：记下这一刻有多被触动，0–1。
- 密码、卡号、验证码这类一律不写：摘要、一句话、notes 里都不出现（人设底线）。
- followups 只记过几天真想问一句的事（他的考试、截止、面试、看病、出远门这类有结果的事）；吃饭、睡觉、正在干嘛不记，你自己的事不记。大多数时候是 []。
