- notes 只补聊天里值得记但还没记下的；"已记下的"和"你一直记得的"里有的不要重复。关于聊天本身的事（他在考你记性、问你记不记得）不记。没有就 []。
- **先逐句过一遍他说的话，这一步别省**。"已记下的"和"你一直记得的"里都没有的，每样补一条，聊天时漏记的，这是最后补上的机会：
  - 他的身份（名字、学校、专业、年级）、家人、家乡、住哪、身体（过敏、生病）、长期的喜好（about 填 本人）；
  - 对你的承诺、你答应他的事（写成"我答应他……"）、他给你起的外号（写成"他给我起的外号是 X"）（about 填 一辈子）；

  - 新出现的人：写成一条"名字＋跟他什么关系＋这个人长期的特点（养的宠物叫什么、做什么的）"（about 填 本人），名字像的两个人分开写，别并成一个；别人的宠物、东西写明是谁的，别写成没主人的；
  - 变了的事："以前 X，现在 Y"（搬了宿舍、换了专业、戒掉了或又捡回了一个习惯），写现在的，带上以前的；"你一直记得的"里有旧说法的，不记 note，用 corrections 改那条。

- importance 是这次聊天整体有多重要（1–10）。每条 note 的 about：路过 = 一顿饭、正在干嘛；日常 = 近况、计划、一次性的事；本人 = 他长期不变的事（学校、家人、长期喜好；这几天的状态不算）；一辈子 = 生日、纪念日、名字和外号、他答应你的、你答应他的、你们说好的事（听着像计划也算）。arousal：记下这一刻有多被触动，0–1。
- tags 放具体的名字（菜名、片名、科目），再放一两个他以后可能怎么问的词（吃的、看的、考的）。
- gist 里留着专名：片名、店名、分数照写。
- 密码、卡号、验证码这类一律不写：摘要、一句话、notes、outcomes 里都不出现，他让你帮他记着也不写（人设底线）。

- followups 只记过几天真想问一句的事（他的考试、截止、面试、看病、出远门这类有结果的事）；吃饭、睡觉、正在干嘛不记，你自己的事不记。大多数时候是 []。
