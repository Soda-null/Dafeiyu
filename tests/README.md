# 测试

> **是什么：** `pytest` 跑的测试，每个文件一行。
> **地位：** 索引。
> **读法：** 查表；跑 `.venv/bin/python -m pytest -q`。

| 文件 | 查什么 |
|---|---|
| `test_skeleton.py` | 七个模块都能 import；大脑、记忆、心情不 import 电话线；人设文件能读 |
| `test_stability.py` | 遗忘公式对得上设计稿 §5.3 的表：各重要度几天模糊、几天想不起；重要度 10 钉住；情绪加成；快忘了才想起涨得多；提三次的中等事撑一年 |
| `test_longterm.py` | 长期条目的一生：小事 12 天后自由召回不出现、标签一提就"被提醒才想起"；重要度 10 的事 400 天后还在底牌；改口取代旧条目并留"曾经"；合并更稳；召回守条数和字数预算 |
| `test_stores.py` | 窗口折叠不删原话；情景按 30 分钟和跨天分界；惦记到期和过期；关系账算天数和连续；日记；心情；夜间例行一天只跑一次、过期惦记变事件、旧情景降级 |
| `test_wechat.py` | 假的 iLink 服务器：发消息的请求头和请求体逐字段对得上官方插件；收消息的游标、超时、-14；登录请求走登录主机不带 token；文字 / 语音 / 图片怎么读；通道只回主人、同一条不回两次、每行一个气泡、游标和 context_token 落盘；出错退避 2 秒 → 30 秒、过期就停；扫码流程等待 / 过期换码 / 确认存凭证、过期太多次放弃 |
| `test_nightly.py` | 夜间例行：鱼日的边界是 03:30；日记从当天的聊天、她的生活线和昨天的日记写出来，生活线存回去，导出文件有它，同一天不写两次；重复的合并、新事实取代旧的；5 次聊天后反思并把重要度夹在 6–8，之后一周内不再反思；模型回坏了只跑机械步骤；没有大脑只跑机械步骤；认识之前的日子不写日记 |
| `test_world.py` | 她的窗口，全用假网页：RSS 和 Atom 解析、B 站条目和热评、网页正文去掉脚本和导航、一个坏源不影响别的；维基查一下；每天逛一次：挑、点开、记见闻和新念头、同一天不逛两次、一周内不重开看过的；聊天里查一下：关于他的事只取没看过网页的第一次回复、查到的记成见闻；最近的见闻进提示词；解析 `look` / `seen`；旧库自动补 `source` 列 |
| `test_reach.py` | 她先开口：门拒绝的每个理由（没认识、夜里、刚聊过、关了、刚决定过、太快、今天够了）；没由头不调模型；有见闻就分享、发成功才记进对话、同一条不再分享；发失败什么都不记；到期的惦记问了就关；她可以决定不说；无聊和纪念日是由头；微信通道在轮询之间推送、每行一个气泡、没凭证不发 |
| `test_stages.py` | 会变的部分：人设文件拆成底子和三档、真文件三档齐全；亲近值的档位和描述；提示词只带当前档的规则、带相处方式卡和近况一句、亲近值变了档就换；反思长出相处方式卡、日记写出近况一句；没聊的日子亲近 −1，聊了不扣 |
| `test_pictures.py` | 图片两头通：AES 加解密和钥匙的三种编码对得上官方插件；下载解密他的图（CDN 地址或 full_url）；上传请求、CDN POST 的密文、响应头、`sendmessage` 的图片项逐字段对；她看图 → 记一句、留成表情包、下次能发回去并计数；微信通道取他的图、文字后发她的表情包；inbox 里的图夜里起叫法收进相册、非图片不动 |
| `test_layers.py` | 性格三层：阶段每晚只走五分之一、没数据不动、十天好心情也出不了上限；底色从原稿起步、一次最多挪 0.15、永远出不了边界、挪够了提示词才提；当日心情睡醒回到阶段定的基线；一天都"开心"把基调抬高、夜里重置精力；认识满 30 天那晚回头看一次、超出的挪动被截、第二晚不再看、挪够了聊天提示词里出现"比刚认识时话多了些" |
| `test_place.py` | 她住哪：定位只留城市和街区、出去的坐标是四舍五入过的；天气一句话；附近的店有名字种类分钟、没有地址、去重；一次跑完存家、店、地图并让她看一次地图、同一天第二次什么都不做；聊天提示词里有住哪、附近、天气 |
| `test_brain.py` | 用 `FakeLLM` 跑每轮流程：回复、随手记和惦记真的写进库；提示词里有底牌、想起的、到期的惦记、时间和关系；改口取代旧条目、问了就关惦记；坏 JSON 当纯文本说、不记；空回复换纯文本重问一次；窗口超了折叠成摘要并进下一轮提示词；隔两小时旧聊天被收尾、补记和惦记写进库；预算超了先砍想起的；心情随这轮变；解析器容忍代码围栏和坏字段 |

测试只用临时目录，不碰 `data/`；全部不需要密钥。时钟都是手拨的（`T0` 加天数），不依赖现在几点。
