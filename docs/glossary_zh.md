# 术语表

> **是什么：** 这个项目的每个代号一行人话。
> **地位：** 索引。新代号在同一次提交加一行。
> **读法：** 查。

| 代号 | 人话 |
|---|---|
| 大肥鱼 / Dafeiyu | DeepSeek 的网友拟人形象：蓝色胖鱼，懒，爱吃白饭。本项目的主角 |
| 电话线 / channels | 收发消息的那层：终端、微信。换了它大脑不动 |
| 大脑 / brain | 拼提示词、调 DeepSeek 的那层 |
| 窗口 / window | 最近 N 轮原话（N = 20），她的工作记忆 |
| 小本本 / notebook | 口语说法，指她记着的关于你的事；代码里是 `memories` 表的长期条目（设计稿 10-26 起） |
| 情景 / episode | 一次聊天（隔 30 分钟算下一次）：起止、滚动摘要、收尾的一段和一句话 |
| 滚动摘要 / 折叠 | 窗口超过 20 轮时，把最老的 10 轮压成几句并进情景的摘要 |
| 长期条目 / memories | 六种：fact 关于你、event 发生过的事、howto 相处方式、insight 看出的规律、self 她的生活线、world 她在网上看到的（见闻） |
| 见闻 / world | 她上网看到的东西，她的口吻加她的看法，带网址；重要度一般 2–5，一两周就淡 |
| 她的窗口 / 逛 | 每天上午 09:30 她从订阅源里挑最多 3 条点开看（决定 9） |
| 订阅源 / sources.json | 她逛的地方的清单：几个 RSS、B 站热门和音乐区；用户随时改 |
| look / 查一下 | 聊天里她想查什么时在回复里填的词，程序去查维基百科再让她回答，一轮最多一次 |
| 先开口 / reach out | 她主动给他发消息（决定 10）：规则的门不花钱，过了门有由头才问她一次，她自己定说不说 |
| 相处方式卡 / howto | 她总结的"怎么和他相处"的规矩，每周反思长出来，每轮都带（决定 11） |
| 近况一句 / recent_self | 每晚写日记时提的一句"最近的我"，几周尺度的心情，进提示词 |
| 熟悉程度 / stage | 亲近值分三档：刚认识（0–24）、熟了（25–59）、很熟（60+），每档有自己的说话规则，写在人设文件里；亲近值存关系账，天为单位 |
| 底色 / traits | 性格最慢的一层（决定 13）：人设原稿 + 五根滑杆（防备、话多、嘴毒、黏人、乐观），每月她自己挪最多 0.15，永远在 −1 到 1 之间 |
| 回头看 / growth | 每 30 天夜里她看一个月的日记和状态走势，写一句"这个月我……"，顺便挪滑杆 |
| 阶段 / phase | 性格中间的一层：基调（−1..1）、劲头（0..1）、在意的事、一句话；每晚八成旧两成新 |
| 当日心情 / mood | 最快的一层：精力、无聊、饿，每轮变；`mood_log` 每轮记一行给阶段层看 |
| 表情包相册 / stickers | 她留下的图，每张有她自己起的叫法；回复里填编号就发（决定 12）；`data/stickers/`，`inbox/` 是用户往里丢图的地方 |
| image_note | 他发图时她记的一句"这是张什么图"，存进对话代替图本身 |
| Incoming / Outgoing | 电话线和大脑之间传的两样东西：他的话 + 图；她的话 + 要发的表情包 |
| 对话凭证 / context_token | 他每条来信带的码；她先开口时用上一张，没有或过期就发不出 |
| 底牌 / profile | 十几条最稳的关于你的事实，每轮都带给模型，不走召回 |
| 稳定度 / stability S | 一条记忆多耐忘，单位天；想起一次变大，相似的合并也变大 |
| 取回度 / retrievability R | 现在能想起的概率 = e^(−天数/S)；< 0.5 模糊，< 0.1 想不起，< 0.02 提醒也想不起 |
| 重要度 / importance | 模型给每条 1–10 的分：身份大事 8–10、计划喜好 5–7、小事 1–4；定初始稳定度 |
| 召回 / recall | 用户说一句话时，从长期条目找相关的几条：相关 × 新近 × 重要打分 |
| 被提醒才想起 | 自己想不起（R < 0.1）但线索很强时还能出来的条目，像"哦对，你说过" |
| 取代 / supersede | 改口：新条目指向旧条目，旧的不删、不再用，可当"曾经" |
| 惦记 / prospective | 带到期日的"要问他的事"，到了就进提示词 |
| 反思 / insight | 每 7 天让模型看最近的事总结出的规律 |
| 生活线 / self | 她自己的事（想换鱼缸、数米粒），日记里连着写 |
| 夜间例行 / nightly | 收尾情景、去重、查矛盾、反思、写日记、压缩、关系账、导出，八步 |
| 日记 / diary | 她自己每天写的一小段 |
| 强度 / strength | 10-26 上午骨架里的旧机制（每天 ×0.97），同日被稳定度取代（决定 6），代码已删 |
| 心情 / mood | 精力、无聊、饿、亲近四个 0–100 的数 |
| 人设 / persona | `docs/persona_zh.md`，原样进提示词 |
| JSON 模式 | 让模型每轮回一段结构化内容（说的话 + 心情 + 记 + 惦记），一次调用顶两次 |
| FakeLLM | 测试用的假模型，给定回复，不花钱不联网 |
| ClawBot / iLink | 腾讯 2026-03 发的官方插件和协议，让自己的 AI 程序接到个人微信里，只能单聊、只能回复；我们照插件 2.4.10 的源码自己写了客户端（决定 7） |
| context_token | 微信每条来信带的一串码，回信时要原样带回去，消息才会落在同一个对话里 |
| get_updates_buf / 游标 | 收消息接口的书签：每次服务器给一个新的，下次带上就只拿新消息；存在 `data/wechat.json` |
| `data/wechat.json` | 微信凭证：bot_token、她的 id、主人的 id、服务器地址、游标、context_token；不进 git |
| box / young-ubuntu | 寝室里一直开着的 Ubuntu 笔记本，她住在那（决定 8）；Mac 上 SSH 别名 `ubuntu-tailscale` |
| systemd 用户服务 | Linux 上让程序开机自动跑、挂了自动重启的机制；"用户"级的不用 sudo |
| linger | 让用户服务在没人登录时也跑的开关（`loginctl enable-linger`） |
| 三行卡片 | 每份文档开头的 是什么 / 地位 / 读法 |
| 住哪 / home | 她住的城市和街区（决定 15），`data/home/home.json`；坐标只到约一公里，不存门牌；也记着那儿的时区，`.env` 没写 `TZ` 时她的钟按它走 |
| 触动 / arousal | 记下这一刻有多被触动（0–1），不是多重要；第二版用它定初始稳定度（设计稿 `memory_v2_zh.md`） |
| 说的是什么 / about | 第二版记下时填的档：路过、日常、本人、一辈子；决定淡得多快，一辈子的钉住 |
| 牵连 / links | 第二版记忆之间的连线：同一次聊天、共同标签、文字重合、模型说有关；想起一条时连着的也涨一点 |
| 待印证 | 决定 21：新的规律或相处方式先是"待印证"（牢固度 7 天，提示词里带"还说不准"），在三个不同的天被重新看出来才转正；夜里看出过时的会淡掉 |
| 记忆体检 / checkup | 逐步喂、隔久再问的评测（设计稿 `checkup_design_zh.md`）：编的朋友小周 90 天剧本，裁判打五档（记住 / 模糊但对 / 说不记得 / 记错 / 编造），按类别对及格线 |
| 写之前挑 / note | 决定 19：写一条记忆前先挑。关于聊天本身的不记；和旧的重复就加固旧的；规律、相处方式各最多 20 条；生活线每晚最多长 1 条 |
| 干过几回 / times | 决定 20：一条记忆发生过几回；重复时加一；提示词里写"（好几回了）""（很多回了）"；到 3 / 6 / 12 回夜里改写成不带单次细节的大意 |
| 一键安装 / install.sh | 仓库根目录的脚本：装环境、写 `.env`、扫码、开机自启；`update` 更新重启，`uninstall` 停掉不删记忆（决定 16） |
| FISH_OWNER | `.env` 里她称呼主人用 他 还是 她；提示词和人设按它换（决定 16） |
| FISH_HOME | `.env` 里手动指定她住哪（纬度,经度），给放在云服务器上的人（决定 16） |
| 附近 / places | 1.5 公里内有名字的吃饭和买东西的地方，只有名字、种类、走几分钟 |
| 空闲时间 / leisure | 一天最多 3 段她有空的时候（设计稿 `free_time_design_zh.md`）：程序只判断有没有空、摆出能做的事，做哪个或什么都不干她自己挑 |
| 工具箱 / 菜单 | 空闲时摆给她的那几样能做的事，每样一句人话，顺序每次打乱，"什么都不干"和别的平起平坐 |
| 在追的 / pastimes | 她在读的书、关注的 UP 主的书签：到哪了、上次碰是哪天；30 天没碰算她自己弃了 |
| 日子 / days | 每轮提示词里的一行"今天是什么日子"：星期、节气、节假日，她理不理都行 |
