# 小屋和小镇的规则

> **是什么：** 小屋长什么样、现状记哪些东西、她能做哪些动作（要什么才做得成、花多久、做完改什么）、时间怎么改屋子、镇上的店。以后程序照这份执行。
> **地位：** 现行（决定 26，2026-10-28）。数字是先拍的，用户随时改；代码 `src/fish/cottage/rules.py` 照这份，改数字两边一起改。为什么这么设计见 `cottage_design_zh.md`。
> **读法：** 查表。想改哪个数，直接改这里。

## 1. 小屋（布局，几乎不变）

**一句话给她：**湖边一间木头小屋，窗外是湖和对岸的树林，屋里有小厨房、靠窗的床、书架和窗台，走 10 分钟到镇上；手机一直带在身上。

一层，一个人住正好。聊天时她只看上面那一句（每轮都发，长了费地方）；下面每一条在她决定空闲干什么时原样给她看（`rules.py` 的 `layout` 读），所以用"你"写；会变的东西（冰箱里有什么、窗台上摆了什么）不写在这里，写在现状里。外形和细节等改鲸鱼娘的人设时一起再定。

- **窗外：** 一片湖，对岸是树林，晴天天很蓝。湖的样子跟着天气变：下雨起雾，刮风有浪，傍晚能看日落。
- **床：** 靠窗。床头有个小抽屉，是你自己的：每晚写给他、但不打算给他看的信放在里面。
- **小厨房：** 一个灶、一口锅、一个电饭煲、一个米缸、一个小冰箱。
- **水槽：** 在灶旁边。
- **桌椅和书架：** 一张桌子、一把椅子、一个小书架。
- **窗台：** 他送你的东西摆在这儿（他 10-28 送过一个长条的大鱼缸，正对着湖；他放了小金鱼，鱼就养在这个缸里，决定 44）。还有两个花盆，柜子里有几包种子（小葱、小白菜、小番茄），想种就种；种下的要隔一两天浇一次水，不然会蔫，再不管会干死。
- **手机：** 一直带在身上。跟他发消息、存表情包、看他发来的链接、刷新闻和 B 站，都用它。它拍不了照，你也发不了照片给他。
- **门口：** 一条小路，走 10 分钟到镇上。

## 2. 现状记什么

这是她能看、不能改的那份文件。打开大概长这样：

实际存成 JSON（`data/cottage/now.json`），键是英文、值是中文；`fish cottage` 照上面这样念出来。手改坏了她这一轮就看不到屋子，聊天不受影响。

```
她：在家，发呆
床：乱
冰箱：鸡蛋 2 个（10-27 买）、青菜 1 把（10-26 买）
米缸：一半
水槽：一口没洗的锅
窗台：空
```

| 一栏 | 可能是什么 | 谁会改它 |
|---|---|---|
| 她 | 在哪（在家 / 在路上 / 在菜店）+ 在干嘛 + 到几点 | 动作开始和结束 |
| 床 | 叠好 / 乱 / 她在睡 | 起床、叠床、午睡、夜里睡 |
| 冰箱 | 每样东西：名字、还够几顿、哪天买的；最多 8 样 | 买菜、做饭、放坏了、他放 |
| 米缸 | 还够几顿，满缸 12 顿；给她看成"满的 / 还有一半 / 快见底了 / 空了" | 做饭、买米、他放 |
| 水槽 | 干净 / 几样没洗的 | 做饭、洗碗 |
| 窗台 | 他送的东西 | 只有他 |
| 花盆 | 两个：空着，或种着什么、种下第几天、长到哪、哪天浇的水 | 她种、浇、摘；时间让它长、蔫、干死（决定 42） |
| 小金鱼 | 养在窗台上他送的鱼缸里（窗台上没缸的话，放鱼时带一个小缸）：名字、哪天喂的、哪天换的水 | 只有他放（一条）；她喂、换水、起名；时间让它抽签做动作、没人管就趴缸底；缸里有鱼，缸拿不走（决定 43、44） |

## 3. 她能做的动作

只摆现在做得成的。她选了，程序按表改现状；她自己描述"做得怎么样"，但不能多出、少掉表里以外的东西。

| 动作 | 要什么才做得成 | 花多久 | 做完改什么 |
|---|---|---|---|
| 煮白饭 | 在家；米缸不空；饿了（饿值 50 以上才摆） | 30 分钟 | 米缸少一顿；水槽多一个电饭煲内胆；煮好时才吃，饿 −35（决定 32） |
| 做饭（有菜） | 在家；米缸不空；冰箱有菜；水槽没洗的不超过 3 样；饿了 | 40 分钟 | 米缸少一顿；最快坏的 1–2 样菜各少一顿；精力 −5；水槽多一口锅；做好时才吃，饿 −50（决定 32） |
| 洗碗 | 在家；水槽有东西 | 10 分钟 | 水槽清空；精力 −3 |
| 给他留东西 | 在家；冰箱里真有那样东西，或者写张纸条（"纸条：想写的话"） | 1 分钟 | 窗台上多一样，标"给他留的"；冰箱里那样少一顿（决定 36） |
| 叠床 | 在家；床乱 | 2 分钟 | 床：叠好 |
| 种东西 | 在家；窗台上还有空花盆；说得出种哪样（小葱 / 小白菜 / 小番茄，种子不限量） | 10 分钟 | 那个花盆种上，当天算浇过水（决定 42） |
| 浇水 | 在家；种着的花盆今天还没浇 | 3 分钟 | 所有种着的都算今天浇过；屋里记一笔，标"日常"，不算找他的由头 |
| 喂鱼 | 在家；有小金鱼；今天还没喂 | 1 分钟 | 今天喂过了；记一笔，标"日常" |
| 给鱼缸换水 | 在家；有小金鱼；上次换水满 3 天 | 10 分钟 | 水是新的；精力 −2；标"日常" |
| 给小金鱼起名 | 在家；有小金鱼；还没有名字；名字 1 到 6 个字 | 1 分钟 | 记下名字，只能起一次 |
| 摘菜 | 在家；有能摘的；冰箱放得下 | 5 分钟 | 进冰箱：小葱一把够 1 顿（剪了会再长），小白菜够 2 顿（摘了花盆就空了），小番茄红几颗算几顿（留在秧上接着结） |
| 午睡 | 在家；白天；精力低于 50 | 1 小时 | 精力 +25；床：乱 |
| 去菜店 | 菜店开着，走到时也还开着；从菜店回来不到 2 小时不再去 | 来回 20 分钟，买 10 分钟 | 出门时记"出门去镇上的菜店（想买……）"，**到家时**才买、才进冰箱，记"从菜店回来了，买了……"；有什么货按到店的时间算（决定 35）；她在 arg 里写想买的；带回最多 5 样，冰箱放得下为限；米缸补满；没卖的记"想要的……没有"；精力 −8 |

身体的事不用她挑，程序替她做：

- **睡觉**：0 点到 8 点床记"在睡"，这时他发消息，她是被吵醒的；8 点以后起床，床变"乱"。精力夜里回到基线（原来就有）。
- **吃饭**：午饭 11:30–13:30、晚饭 17:30–19:30，到点她在家又没在忙，就吃：冰箱有菜做饭，只有米煮白饭，什么都没有就记一句"饿着"。两个半小时内自己做过饭，这顿就算吃过了。
- 到点吃的饭在屋里的记录里标"日常"：日记照样看得到，但不算她先开口找他的由头（10-28 真模型试跑：她每顿饭后都发"饭做好了，你吃了没"）。
- **饭分两步记**（决定 32）：开始时记"开始做晚饭，用鸡蛋"，做好时记"晚饭做好了，吃了"，吃了才算吃过、才不饿。原来开始做就记成"做了饭"，她同时看到"已经吃了"和"正在做"，一会儿说吃完了一会儿说去做饭。
- **饿和精力只跟着时间、吃饭、睡觉走**（决定 32）：醒着每小时饿 +3、精力 −2.5；吃饭降饿，午睡和夜里的觉回精力。跟他聊天不加不减，聊到吃的也不变（原来每句话饿 +2、精力 −1，聊一百多句就把她聊到饿满格、精力见底）。到饭点也不再额外显得饿，饭点有真的饭。

数字说明：饿和精力都是 0 到 100。饿值超过 70 她会"满脑子白饭"，精力低于 30 她会"不太想打字"，这两条线现在就有（`mood/state.py`）。

## 4. 时间怎么改屋子

夜里整理时一起算，不调模型。

| 什么 | 规则 |
|---|---|
| 床 | 每天早上起来变"乱"，不叠就一直乱 |
| 青菜、豆腐、肉 | 买回来 3 天后坏，自动扔掉，记一句"青菜放坏了，扔了" |
| 西红柿、土豆 | 7 天 |
| 鸡蛋、南瓜、萝卜 | 14 天 |
| 他放进来的、店里不卖的 | 不坏，算一顿 |
| 米 | 不坏 |
| 水槽 | 不洗不会自己变干净 |
| 她在哪 | 动作结束自动回家 |
| 花盆（决定 42） | 每天早上 8 点看一次：上回浇水不到 3 天就长一天；3 天没浇就蔫了、不长；浇了第二天早上"缓过来了"，再一天才接着长；6 天没浇就干死、拔掉，花盆空出来 |
| 小葱 | 长 3 天冒芽，8 天一指高，14 天能剪；剪了 7 天又能剪 |
| 小白菜 | 长 3 天冒芽，10 天四片叶子，25 天能摘，摘一次就完 |
| 小番茄 | 长 6 天冒芽，20 天一尺高，35 天开花，50 天结青果子，60 天第一颗红；之后每 3 天红一颗，秧上最多攒 6 颗 |
| 从花盆摘的 | 小葱放 5 天坏，小白菜 3 天，小番茄 7 天 |
| 小金鱼做什么（决定 43） | 每个钟头抽一次签，同一天同一个钟头永远抽到同一个：游、转圈、吐泡泡、躲水草、贴着玻璃看、拱沙子、发呆、窜一下……0 点到 8 点睡着；今天没喂（10 点以后）就在水面绕圈要吃的；2 天没喂或 7 天没换水就趴缸底。每天有 2 个钟头的动作记进屋里（标"日常"，日记和信看得到，不算找他的由头）；趴缸底、缓过来各记一次。**它不会死**，喂了、换水了就缓过来 |

## 5. 镇上的店

### 菜店（第一版）

- 离家走 10 分钟。
- 每天 7:00–19:00 开门，每周二休息。
- 卖：米、鸡蛋（一次够 3 顿）、青菜、豆腐（各 1 顿）、肉、西红柿、土豆（各 2 顿）。
- 货会变：每天缺 1 样（同一天一直缺同一样）；下午 3 点以后青菜卖完了。
- 有当季的：9–11 月有南瓜（3 顿），12–2 月有萝卜（2 顿）。

### 花店（第二批，先写着）

- 离家走 15 分钟，每周一不开门。
- 卖当季的花和小盆栽。买回来放窗台，隔几天要浇水，不浇会蔫。

## 5a. 他在电脑上放东西、拿东西（决定 36）

在 Mac 上打 `yu 一句大白话`：`yu 往冰箱放两盒牛奶`、`yu 把她给我留的东西拿走`、`yu 窗台上放一束向日葵`、`yu 米缸给她加满`。模型只负责把这句话翻成"放 / 拿、放哪（冰箱、米缸、窗台）、什么、几份"，真的放和拿还是照规则：冰箱满了放不进，屋里没有的拿不走。拿走的东西屋里会记一笔"他从窗台上拿走了……"，她下次聊天看得到。老写法 `yu put 鸡蛋`、`yu sill 一盆薄荷` 照样能用。

## 5d. 他送她一条小鱼（决定 43）

`yu 给她养条小鱼`：往窗台上那个鱼缸里放一条小金鱼（没有缸才带一个小缸），只能放一次，鱼也拿不走。之后她自己喂、换水、起名字；小鱼做什么见上面 §4 的表。

## 5c. 他来她这儿（决定 41）

他可以来她的小屋，比如来吃晚饭。在微信里说"我到你家门口了""今晚六点过去"，或者在电脑上 `yu 我今晚六点过去她那吃晚饭，待到九点`；走的时候说"我先回去了"。

- 约好几点来，屋里记"他说 18:00 过来"；到了那个点才算他来了（提前说到门口了就提前）。改天才来的不算，她记成惦记。
- 他在的时候：屋里写着"他这会儿就在你屋里"，你们是当面说话；到饭点做两人份（菜和米都用两份），他说要来吃饭，她会等他到了再做；她不主动给他发消息，也不去忙自己的空闲。
- 他说了几点走，到点就算他回去了；没说，就一直待到他说走（最晚 23:30，这个点不告诉她）。他说"我先回去了""到家了"，就算她回话时忘了，程序也算他走了。
- 来了、走了都记进屋里，当晚的日记和抽屉里的信会写到。

## 5b. 聊天里说要去做的（决定 35）

她在聊天里说"我去买菜了""我去洗碗"，程序真的去做：每轮聊天她看得到"你现在能做的"（和空闲时的菜单一样，只有现在做得成的才列），说要去做就在回复里填 do（去菜店再写想买的）。做不做得成、结果是什么，照上面的规则：周二菜店关门就去不成，路上的半小时手里还没有菜，到家了冰箱才满。她没填 do、屋里记录也没有的事，就是没做，不能说做了。

## 6. 她不能做的

- 不能在笔记和日记里写屋里没发生的事。"煮了碗面"没煮就不记；"想煮碗面"可以。

- 不能用说话改现状。她说"我冰箱满满的"，冰箱不会变满。
- 不能去规则里没有的地方。"去城里吃火锅"没有这家店，但她可以想，可以跟他说想去。
- 第一版没有钱这回事（`cottage_design_zh.md` §8 第 2 件）。
