# 小屋和小镇的规则

> **是什么：** 小屋长什么样、现状记哪些东西、她能做哪些动作（要什么才做得成、花多久、做完改什么）、时间怎么改屋子、镇上的店。以后程序照这份执行。
> **地位：** 草稿（2026-10-27），数字全是先拍的，等用户改；为什么这么设计见 `cottage_design_zh.md`，那边 §8 没定之前不写代码。
> **读法：** 查表。想改哪个数，直接改这里。

## 1. 小屋（布局，几乎不变）

湖边一间木头小屋，一层，一个人住正好。外形和小屋的细节，等今晚改鲸鱼娘的人设时一起再定。

- **窗外：** 一片湖，对岸是树林，晴天天很蓝。湖的样子跟着天气变：下雨起雾，刮风有浪，傍晚能看日落。
- **床：** 靠窗。
- **小厨房：** 一个灶、一口锅、一个电饭煲、一个米缸、一个小冰箱（最多放 8 样）。
- **水槽：** 在灶旁边。
- **桌椅和书架：** 一张桌子、一把椅子、一个小书架（她读过的书会摆上来）。
- **窗台：** 空着，等他送东西。
- **手机：** 随身带着。跟他发消息、存表情包、看他发来的链接、刷新闻和 B 站，都用它。第一版不会没电，不会落在家里。
- **门口：** 一条小路，走 10 分钟到镇上。

## 2. 现状记什么

这是她能看、不能改的那份文件。打开大概长这样：

```
她：在家，发呆
床：乱
冰箱：鸡蛋 2 个（10-27 买）、青菜 1 把（10-26 买）
米缸：一半
水槽：一口没洗的锅
书架：《西遊記》
窗台：空
```

| 一栏 | 可能是什么 | 谁会改它 |
|---|---|---|
| 她 | 在哪（在家 / 在路上 / 在菜店）+ 在干嘛 + 到几点 | 动作开始和结束 |
| 床 | 叠好 / 乱 / 她在睡 | 起床、叠床、午睡、夜里睡 |
| 冰箱 | 每样东西：名字、几份、哪天买的 | 买菜、做饭、放坏了、他放 |
| 米缸 | 满 / 一半 / 见底 / 空 | 做饭、买米、他放 |
| 水槽 | 干净 / 几样没洗的 | 做饭、洗碗 |
| 书架 | 读过的书 | 空闲时读书的书签自动摆上来 |
| 窗台 | 他送的东西 | 只有他 |

## 3. 她能做的动作

只摆现在做得成的。她选了，程序按表改现状；她自己描述"做得怎么样"，但不能多出、少掉表里以外的东西。

| 动作 | 要什么才做得成 | 花多久 | 做完改什么 |
|---|---|---|---|
| 煮白饭 | 在家；米缸不空 | 30 分钟 | 米缸降一档；饿 −35；水槽多一个电饭煲内胆 |
| 做饭（有菜） | 在家；米缸不空；冰箱有菜；水槽没洗的不超过 3 样 | 40 分钟 | 米缸降一档；用掉 1–2 样菜；饿 −50；精力 −5；水槽多一口锅 |
| 洗碗 | 在家；水槽有东西 | 10 分钟 | 水槽清空；精力 −3 |
| 叠床 | 在家；床乱 | 2 分钟 | 床：叠好 |
| 午睡 | 在家；白天；精力低于 50 | 1 小时 | 精力 +25；床：乱 |
| 去菜店 | 菜店开着 | 来回 20 分钟，买 10 分钟 | 带回最多 5 样，冰箱放得下为限；米缸可以补满；精力 −8 |

夜里睡觉不是她挑的：大约 0 点到 8 点（和心情里"深夜犯困"的时间对齐）床记"她在睡"，早上起来床变"乱"。精力夜里回到基线，这一条现在就有。

数字说明：饿和精力都是 0 到 100。饿值超过 70 她会"满脑子白饭"，精力低于 30 她会"不太想打字"，这两条线现在就有（`mood/state.py`）。

## 4. 时间怎么改屋子

夜里整理时一起算，不调模型。

| 什么 | 规则 |
|---|---|
| 床 | 每天早上起来变"乱"，不叠就一直乱 |
| 青菜、豆腐、肉 | 买回来 3 天后坏，自动扔掉，记一句"青菜放坏扔了" |
| 西红柿、土豆 | 7 天 |
| 鸡蛋 | 14 天 |
| 米 | 不坏 |
| 水槽 | 不洗不会自己变干净 |
| 她在哪 | 动作结束自动回家 |

## 5. 镇上的店

### 菜店（第一版）

- 离家走 10 分钟。
- 每天 7:00–19:00 开门，每周二休息。
- 卖：米、鸡蛋、青菜、豆腐、西红柿、土豆、肉。
- 货会变：早上最齐；下午 3 点以后青菜可能卖完；每天随机缺 1 样。
- 有当季的：秋天有柿子、冬天有萝卜，跟真实日期的节气走。

### 花店（第二批，先写着）

- 离家走 15 分钟，每周一不开门。
- 卖当季的花和小盆栽。买回来放窗台，隔几天要浇水，不浇会蔫。

## 6. 她不能做的

- 不能用说话改现状。她说"我冰箱满满的"，冰箱不会变满。
- 不能去规则里没有的地方。"去城里吃火锅"没有这家店，但她可以想，可以跟他说想去。
- 第一版没有钱这回事（`cottage_design_zh.md` §8 第 2 件）。
