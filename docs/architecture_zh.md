# 大肥鱼是怎么搭的

> **是什么：** 代码的七个模块各管什么、一条消息怎么从电话线走到大脑再回来、记忆存在哪、按什么顺序建。
> **地位：** 现行（用户 2026-10-26 认可的方案）。改模块边界要先改这里再改代码。
> **读法：** 先看 §1 的图和 §2 的表；写代码前再看 §3–§5。

## 1. 一条消息怎么走

```
终端 / 微信 ──> channels ──> 接线员（brain/respond.py）
                                 │ 问各节点
        memory：这句话让她想起什么（recollect）、今天聊过的（daychat）
        mood：她此刻什么状态    cottage：屋里什么样    world：住哪、今天什么日子
                                 │ 装成一个 Situation
                          大脑本身（brain/reply.py）──> DeepSeek
                                 │ 她的回复
        接线员记下：两句话进聊天记录、她的笔记、表情包、心情和亲近
                                 │
                             channels ──> 你
```

1. **电话线**（`channels/`）收到你一句话（可能带一张图），交给接线员；回她的话（可能带一张她的表情包）。它只负责收发，不懂内容。两头之间传的是 `messages.py` 里的 `Incoming` / `Outgoing`。
2. **接线员**（`brain/respond.py` 的 `Brain`）不自己翻任何东西，挨个问节点：记忆节点回答"这句话让她想起什么、今天聊过什么"（`memory/recollect.py`），心情、小屋、外面的世界各回各的。答案装成一个 `Situation`（节点化第 2 步，`nodes_design_zh.md`）。
3. **大脑本身**（`brain/reply.py`）只认 `Situation`：拼提示词、问 DeepSeek、读回复。它不认识记忆的表、小屋的文件、心情的存法，换哪个都不用动它。
4. 回复发回电话线；接线员把这一轮记下：对话进聊天记录，她的笔记进记忆，心情按这轮聊了什么微调。

**没人说话的时候**（节点化第 3 步）：电话线每次轮询完叫一声 `tick`，时钟走一格，在总线上发"时间走了"（`TimePassed`）。谁听、按什么顺序，只写在 `src/fish/app.py` 一张表里：小屋跟着时间走（睡觉、做饭、菜坏），并在总线上喊这一步干了什么（第 4 步："心情该动了""吃了""睡了""屋里出了件事"），心情节点只听"心情该动了"改自己；先开口节点想想要不要找他（"最近屋里出了什么事"是问小屋节点的，不是听来的），空闲节点看看有没有一段空闲。她先开口说的那句在总线上发 `SheSaid`，聊天记录订它记下来。以后加一个跟时间有关的东西（比如屏幕），在这张表里加一行就行。
4. **每天夜里**（`routines/`）：把今天的对话过一遍，值得记的写进小本本，写一条日记，让久不提的旧事淡一点。

## 2. 七个模块

| 模块 | 管什么 | 人话 | 依赖谁 |
|---|---|---|---|
| `channels/` | 收发消息。`terminal`；`wechat`（`ilink.py` 是腾讯 ClawBot 的 HTTP 协议，决定 7） | 电话线，随便换 | `brain` |
| `world/` | 只管"看"：RSS、B 站、维基、维基文库、网页正文、今天是什么日子（决定 9、24；`docs/world_design_zh.md`） | 她的窗口 | 无（只用标准库） |
| `persona/` | 读 `docs/persona_zh.md`，给大脑一段"她是谁" | 她的人设 | 无 |
| `memory/` | 记忆的数据和数学，不调模型（§3，细节在 `memory_design_zh.md`） | 她的脑子里记着什么 | `storage` |
| `mood/` | 四个心情值和它们怎么变（§4） | 她今天什么状态 | `storage` |
| `brain/` | 拼提示词、调 DeepSeek、解析回复 | 真正"想"的地方 | `persona` `memory` `mood` |
| `routines/` | 定时跑的事：夜间整理、写日记、淡化；天气（她的空闲时间不是定时的，在 `brain/leisure/`，决定 24） | 她睡觉时脑子在整理 | `memory` `mood` `brain` |
| `storage/` | SQLite 读写，一个文件 `data/fish.db` | 所有东西存哪 | 无 |
| `cottage/` | 她的湖边小屋：屋里此刻的样子（`data/cottage/now.json`）、她能做的动作、时间怎么改屋子（决定 26；`docs/cottage_rules_zh.md`） | 她住的地方，是现实不是记忆 | 无（只用标准库） |

**铁律：** `brain/`、`memory/`、`mood/` 不许 import `channels/`。换电话线不动大脑。`world/` 不调模型、不认识大脑；`brain` 和 `routines` 用它。`cottage/` 也一样：不调模型、不认识大脑，屋子只被他、规则、时间改。

## 3. 记忆：全在 `memory_design_zh.md`

记忆是这个项目最重要的部分，单独一份文件：[`memory_design_zh.md`](memory_design_zh.md)。一句话版：窗口当工作记忆只放当下，其余全在一个 SQLite 文件里；七种记忆（原话、情景、长期条目、惦记、日记、心情、关系账），每条长期条目有"稳定度"，想起一次更耐忘，久不提就先模糊后想不起，夜里整理、合并、写日记。10-26 上午这一节写的"小本本每天 ×0.97"已被那份设计取代（决定 6）。

## 4. 性格三层（决定 13）

| 层 | 变多快 | 是什么 | 在哪 |
|---|---|---|---|
| 底色 | 月 | 人设原稿（不改写）+ 五根滑杆，她每月回头看自己挪一小格，有界 | `persona/`、`memory/traits.py` |
| 阶段 | 天到周 | 基调、劲头、在意的事、一句话；每晚八成旧两成新 | `memory/phase.py` |
| 当日 | 小时 | 精力、无聊、饿；每轮变，时钟加偏移，夜里回到阶段定的基线 | `mood/state.py` |

亲近值是关系那一层的（`memory/relationship.py`），天为单位，分三档换说话方式。所有数进提示词时都翻成人话（"有点困，不太想打字""心情基调偏低"），不丢数字给模型。全文在 `docs/decisions.md` 第 13 条。

## 5. 数据存哪

- 全在 `data/fish.db`（SQLite）；表的清单在 `memory_design_zh.md` §9。
- `data/` 不进 git。备份 = 复制这一个文件；重置 = 删掉它。
- 密钥在 `.env`，由 `src/fish/config.py` 读，别处不碰环境变量。
