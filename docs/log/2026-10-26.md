# 日志 — 2026-10-26

## 做了什么

- 定了项目方向：像朋友、不像工具的 AI，先终端后微信（决定 1–5）。
- 照 Yaqi 仓库的结构建了骨架：入口三件、`docs/` 账本、七个模块的空壳、测试、脚本、提交钩子。

- 查了 2024–2026 的几篇记忆系统论文（Generative Agents、MemoryBank、MemGPT、arXiv 2605.08538 等），写了记忆设计稿：七种记忆、稳定度 / 取回度的遗忘数学、夜间八步、每轮流程、代码架构、数据表、验收脚本。
- 用户全批设计稿 §11（决定 6）。按它做完记忆的数据层：`stability.py`、`longterm.py`、`retrieval.py`、`episodes.py`、`prospective.py`、`relationship.py`，窗口加折叠，八张表；`notebook.py`、`recall.py` 删除。夜间例行不用模型的两步接上。
- 大脑接通（§2 第 3、4 步）：`brain/respond.py` 每轮流程、三份提示词模板、JSON 回复解析、字数预算、`FakeLLM`；心情 `after_turn` 第一版；`python -m fish [chat|nightly|show]`；包装成可安装的包（`pip install -e .`）。用户填了 `.env`，在终端真聊过了。
- 微信通道（决定 7）：读了腾讯官方插件 `@tencent-weixin/openclaw-weixin` 2.4.10 的源码（unpkg 上，MIT），照它写 `channels/ilink.py`（请求头、`base_info`、扫码登录、`getupdates` 长轮询、`sendmessage`、`getconfig` / `sendtyping`）和 `channels/wechat.py`（只回主人、去重、每行一个气泡、退避、-14 提示重扫）；`python -m fish wechat [login]`。用户当晚扫码成功，她在微信上回话了。

- 搬家（决定 8）：`scripts/deploy_box.sh`、`scripts/systemd/` 三个服务文件、`docs/box_zh.md`；`.env` 加 `TZ=`，`config.py` 读到就 `tzset`，她的钟跟用户走。当晚部署完成：box 上 48 个测试过，服务 active，linger 开了，定时器下次 10-27 用户时区 03:30（第一版定时器按 box 自己的时区算，改成带时区的 OnCalendar 才对）。Mac 上的 `fish wechat` 停了。

- 夜间例行八步（§2 第 6 步）：`brain/consolidate.py` 四次模型调用（合并、取代、反思、日记）+ 四份提示词；`routines/nightly.py` 按"鱼日"（03:30 为界）跑一次；`routines/export.py` 导出小本本。6 个新测试。
- 用真模型在 box 记忆的**副本**上试跑了一夜：收尾、两条反思、一篇日记、一条生活线，都像她。顺手发现两个 bug：（1）聊了 54 句她一条随手记都没写（提示词说"大多数轮次是 []"把模型吓住了，改成"说到他自己的事当轮就记"）；（2）心情的时钟偏移每轮都被存进去，上午精力涨到 100、深夜会崩到 0，改成只在提示词里加偏移、不存；夜里加一步 `rest()`。收尾笔记的日期改用那次聊天开始的日期。

- 用户要给她"通往外界的窗口"。从 box 和 Mac 实测了哪些源能到（RSS、B 站热门、维基都行；DuckDuckGo 给程序回挑战页；微博 403），写了 `docs/world_design_zh.md`：她为自己上网不是替他办事，每天上午挑几条记成见闻（第六种记忆 `world`），聊天里能查维基，网页内容只当资料不当指令。等用户点头 §7（Q5）。

- 用户批了（决定 9），加"听听歌刷刷视频"。做完她的窗口：`src/fish/world/`（RSS、B 站热门 / 音乐区 / 热评、维基、网页正文、订阅源）、`brain/world.py` + 两份提示词、`routines/browse.py`、聊天里的 `look` / `seen`、第六种记忆 `world` 和 `source` 列（旧库自动补列）、`fish browse`、09:30 定时器；人设底线改了；11 个新测试。实测：6 个源拿到 18 条，B 站热评能看，维基"鲸落"能查；知乎 RSS 空、36 氪格式坏，去掉。

- 用户问她为什么不主动找他。实测微信能用上次的对话凭证先发（用户收到了），记决定 10，做了"她先开口"：`brain/reach.py` 规则的门 + 由头 + 问她一次；微信服务轮询之间 `tick`；发成功才记进对话。8 个新测试。

- 用户问性格是写死的还是会变的，定了决定 11：核心性格写死，做了会变的三样——相处方式卡（`howto`，反思总结、每轮带）、近况一句（日记提、存关系账）、熟悉程度三档（人设文件新一节，只有当前档进提示词；一天没聊亲近 −1）。7 个新测试。

- 用户要她能看图、会发表情包（决定 12）。实测：DeepSeek 接口能看图；微信自带表情代码在机器人消息里不显示；官方插件源码里读到收图解密和上传发图的协议（AES-128-ECB、CDN）。做了 `channels/ilink.py` 的收发图、`memory/stickers.py` 相册、`messages.py`（`Incoming`/`Outgoing`）、聊天提示词的 `image_note` / `keep_sticker` / `sticker`、夜里给 inbox 的图起叫法。加依赖 `cryptography`。6 个新测试。真机验证：用户收到她的图；用户发的 Q 版形象图她看懂了（"尾巴那条，是鲸鱼吧。我是鱼"）。第一次把 JSON 原文漏给了用户（图片轮模型先说人话再写 JSON、串里带换行，老解析器失败后发了原文），解析器改宽容、永不发 JSON 原文，第二次正常。部署脚本改成测试不过不推。
- 用户截图：他把一句话拆成两条发（"……路上的" / "店"），她把"店"单独当一条回了"你在说什么"。改了微信通道：来消息后再快速看两眼（2.5 秒）把接着发的合成一轮；提示词说半句、一个字是接上一条的，"嗯"可以不回；JSON 里 say 留空就是她选择不回。两个进程同时逛网的撞车也改成原子认领。

- 用户提出性格三层，并说底色不想由他掌握。记决定 13（取代决定 11 的"底色只能用户改"）：底色 = 原稿 + 五根有界滑杆，每 30 天她自己回头看挪一小格（`traits.py`、`prompts/growth.md`）；阶段 = 基调 / 劲头 / 在意 / 一句话，每晚八成旧两成新（`phase.py`，日记调用顺手改那句）；当日 = 精力 / 无聊 / 饿，每轮记一行 `mood_log`，夜里回到阶段定的基线；亲近值搬进关系账（旧库自动搬）。6 个新测试，97 个全过。
