# 记忆第二版：重要是攒出来的

> **是什么：** 把"记下时打一个 1–10 分、从此定死"换成人脑的做法：一条记忆有多牢，由当时多触动、和他多相关、之后用了几次、和别的记忆连了多少慢慢攒出来。附她现在 38 条记忆的试算。
> **地位：** 设计稿（2026-10-27），§7 等用户定。定了就并进 `memory_design_zh.md`，改掉它的 §5.1、§5.2、§5.3 和 §5.4 第 2 步。
> **读法：** §0 看为什么改，§1 看一句话总结，§2–§5 是四个来源，§6 看试算结果，§7 是要定的事。

## 0. 为什么改

现在每条记忆记下时，模型凭感觉打一个 1–10 的重要度，初始稳定度 S₀ = 2.1^重要度 天，之后这个分再也不变。拿她 10-27 真实的 38 条记忆推算，假设以后再不提：

- 她的**生日**（他们俩定下的日子）只打了 7 分，一年后变模糊。生日该一辈子记得。
- 才认识**一天**就下的两条结论（关于他的作息、他说话的习惯）打了 7 分，要记一年。一天的印象不该这么牢。
- "想把鱼缸弄成湿地"记了**四遍**（#4、#8、#15、#36），夜里没合并。
- 表里有个 `arousal`（当时多触动）字段，从第一天起就没人填，全是 0。情绪本来是人记忆最强的信号，我们没用上。

根子是：**人脑没有"一记下就定死的重要度"**。一件事有多重要，是后来攒出来的。

## 1. 一句话

> 一条记忆的牢固程度（稳定度 S）从四个来源攒：**记下时**多触动、说的是什么；**用到**一次涨一次；**连着**的记忆被想起时它也被碰一下；**夜里**挑着重放、相似的并成大意。生日、承诺这类**一辈子的事**直接钉住。

四个来源对应人脑的四件事：

| 人脑 | 鱼 | 现在有没有 |
|---|---|---|
| 当时越触动记得越牢（杏仁核给海马体加码） | 记下时填 `arousal`，S₀ 按它放大 | 字段有，没填 |
| 和自己有关的事好记 | 记下时填"说的是什么"：路过 / 日常 / 本人 / 一辈子 | 没有，只有一个分 |
| 每回想一次加固一次，快忘时想起涨得多 | 想起一次 S ×(1 + 1.5(1−R)) | **有** |
| 一个念头带出连着的念头；旁边的被顺带复习 | 记忆之间连线；想起 A，连着的 B 也涨一点 | 没有 |
| 睡觉时挑"以后用得上"的重放；相似的经历融成一个大意，细节淡掉 | 夜里重放当天最触动的几条；≥3 条同题的事并成一条大意 | 合并有但太弱 |

## 2. 记下时：不问"多重要"，问两个具体的

聊天和收尾的 JSON 里，每条 note 不再填 `importance`，改填：

- **`arousal`（0–1）**：记下这一刻，他或她有多被触动。0 平淡，1 一辈子忘不了。提示词要写清楚：是"多触动"不是"多重要"。"他中午吃了什么"0.1，"他许了一个认真的承诺"0.8。
- **`about`**：这条说的是什么。**路过** = 吃了什么、正在干嘛、今天的安排；**日常** = 他的近况、计划、一次性的事；**本人** = 他长期不变的事（学校、专业、家人、长期喜好、长期状态）；**一辈子** = 生日、纪念日、双方的承诺、名字。她自己的事（self）和见闻（world）按同一把尺子。

初始稳定度：

> **S₀ = 4 天 × (1 + 3·arousal) × 倍数**，倍数：路过 ×1、日常 ×3、本人 ×40；一辈子 → 钉住（S = ∞）。

几个例子（都按不再提算）：某顿饭吃了什么（路过，0.2）S₀ = 6 天，4 天模糊、15 天想不起；某天去运动了一次（日常，0.3）S₀ = 23 天，16 天模糊、52 天想不起；他在哪上学（本人，0.3）S₀ = 304 天，7 个月模糊、1.9 年想不起；生日：永远。

**规律和相处方式（insight / howto）另算**：反思长出来的规律，背后的证据跨几天由**程序**数（它连着的记忆的日期有几个不同的天），不问模型。证据 < 3 天的，S₀ = 7 天，标"待印证"；之后每来一条印证它的记忆（夜里连上线），S 按"想起一次"涨。印证够了它自然就牢了；没人印证，两周就淡。这样"认识一天就下的结论"再也记不了一年。

旧的 `importance` 列留着，改成**算出来的**：importance = round(log₂.₁ S₀)，钉住 = 10。底牌、召回打分、导出都不用改接口。

## 3. 用到：不变

想起一次：S ← S × (1 + 1.5 × (1 − R))。快忘了才想起涨得多，刚聊过又提几乎不涨。这是现在就有的，是四个来源里唯一已经在工作的，所以她现在生日的 S 已经从 180 涨到了 271（被想起 15 次）。

## 4. 牵连：记忆之间连线

新表 `links(a, b, weight, why)`，无向，weight 0–1。连线从四处来，程序连三种，模型连一种：

| 为什么连 | weight | 谁连 |
|---|---|---|
| 同一次聊天里记下的 | 0.3 | 程序，记下时 |
| 有共同标签 | 0.5 | 程序，记下时 |
| 文字重合（汉字二元组 ≥ 0.25，**去掉数字和日期再算**，不然"他2026-10-26"把所有条都连上了） | 0.4 | 程序，记下时 |
| 夜里模型说"这几条说的是同一件事 / 同一个话题" | 0.7 | 模型，夜里一次调用，只看当天的新条目和它们的候选 |
| 改口、合并 | 1.0 | 程序 |

连线做三件事：

1. **顺带加固。** 想起 A 时，和 A 连着的每条 B：S_B ← S_B × (1 + 0.3 × weight × 1.5 × (1 − R_B))。只涨 S，**不重置** B 的"上次想起"时间（轻轻碰一下不等于真想起；不然聊学校就把某顿饭一直续着命）。R_B < 0.02 的碰不醒。
2. **突然想起。** 每轮召回出的几条里，挑连线最强的一条邻居（weight × R 最大），如果它本身没被召回，就作为"顺带想起的"放进提示词，她想提就提。这就是设计稿 §5.7 的"突然想起"，不用再单独做。
3. **牢固程度看连得多不多。** 召回打分里的"重要度/10"换成**牢固度** = min(1, log S / log 400) × (1 + 0.1 × 连线数)，上限 1。连得多的条目是她记忆里的"枢纽"，更容易被想起，更容易被加固，像人脑里反复用到的那些念头。

## 5. 夜里：重放、并成大意、待印证的转正

夜间例行第 2 步"去重合并"扩成三小步（其余六步不动）：

- **2a 重放。** 当天新记的里挑 3 条：arousal 最高的、和有开着的惦记连着的。各当作"快忘时想起一次"（S × 2.35）。人睡觉时海马体挑的就是"情绪强的、没完的"。
- **2b 并成大意。** 同一组（模型分的组或共同标签）里 ≥ 3 条 `about` 是路过 / 日常的事，30 天内 → 问模型写一条大意（"他常去同一家快餐店，嫌食堂"），kind 按内容定（多半是 fact 或 insight），S = 三条里最大的 × 1.3，和三条都连 1.0；三条原件 S × 0.7（细节让位给大意，这就是人的"干扰"）。现在的两两合并只留给**字面几乎一样**的（≥ 0.6）。
- **2c 转正。** 待印证的 insight / howto，连着的记忆跨 ≥ 3 天了，就按 §2 的本人倍数重算 S₀（保留已经涨过的部分）。

以后再做（不在这版）：R < 0.5 的条目夜里改写得更粗、原文藏起来（真的变模糊）；把两三条混成一个梦早上说给他听。

## 6. 试算：她现在的 38 条

`scripts/memory_v2_trial.py` 拿寝室机上 10-27 的真实记忆跑了一遍：问了模型一次（每条的 arousal、about、分组），然后按新旧两套规则推算。逐条的结果在 Mac 本地 `data/memory_v2_trial_2026-10-27.md`（他的聊天内容，不进 git）；这里只写类别。

**情景 A：记下之后再也不提。** 38 条（不含见闻）几天后 清楚 / 模糊 / 想不起：

| | 7 天 | 30 天 | 90 天 | 1 年 |
|---|---|---|---|---|
| 旧规则 | 29 / 9 / 0 | 12 / 17 / 9 | 6 / 13 / 19 | 0 / 6 / 32 |
| 新规则 | 29 / 9 / 0 | 11 / 18 / 9 | 11 / 0 / 27 | 3 / 8 / 27 |

一年后新规则还记得的 3 条是生日、两条承诺（钉住）；8 条模糊的是关于他本人和她住哪的；旧规则一年后一条清楚的都没有。90 天那列新规则"不上不下"的少了：要么还清楚，要么干脆忘了，中间模糊的几乎没有，这更像人。

单条看：

| 条目 | 旧：模糊 / 想不起 | 新 |
|---|---|---|
| 她的生日 | 187 天 / 1.7 年 | 永远 |
| 他对她的一个认真的承诺 | 187 天 / 1.7 年 | 永远 |
| 他在哪上学 | 262 天 / 2.4 年 | 211 天 / 1.9 年 |
| 她住哪 | 59 天 / 197 天 | 211 天 / 1.9 年 |
| 某顿饭吃了什么 | 3 天 / 10 天 | 4 天 / 15 天 |
| 某晚的一次活动 | 13 天 / 45 天 | 16 天 / 52 天 |
| 一条关于他说话习惯的规律（一天的证据） | 125 天 / 1.1 年 | 待印证：5 天 / 16 天 |
| 一条相处方式（一天的证据） | 125 天 / 1.1 年 | 待印证：5 天 / 16 天 |

**情景 B：接下来 90 天他每周提一次学校和食堂，别的一概不提。** 90 天后：

- 直接提到的（学校、食堂）两套都清楚。
- 连着的：他吐槽过的一笔学校开销，旧模糊、新清楚；一条关于他和食堂的规律，旧模糊、新清楚；她住哪（3 条），旧模糊、新清楚（它们和学校连着）。
- 没连着的照样忘：那次活动、一节课、一份作业，两套都想不起。
- 那顿饭，旧想不起、新模糊："你好像有次在外面吃了啥来着"。顺带碰到的能留个影，不会复活。

模型分出的组里，三组是夜里该并成大意的候选：鱼缸（5 条）、学校和食堂（4 条）、修 bug（4 条）。

## 7. 要用户定的事

1. **换掉 1–10 分**：记下时改填 arousal 和 about，S₀ 按 §2 算。
2. **一辈子的事钉住**：生日、纪念日、名字一定钉；**承诺**要不要钉？试算里"努力让她看到外面的世界"#16 也被当成承诺钉住了。建议：钉，直到兑现或食言，那时改成一条 event（"他说过要……，后来……"），不再钉。
3. **数字**：底 4 天、触动最多 ×4、日常 ×3、本人 ×40。觉得忘得快或慢，改这四个数；试算脚本可以重跑看效果。
4. **连线和夜里三小步**一起做，还是先只做 §2？建议一起做：§2 单独上，"本人"的事不提就会在半年后淡掉，靠连线顺带加固才像人。

定了记成决定，然后按 §2 → §4 → §5 的顺序做，每步带测试；她现有的记忆按新规则重算一次（用试算脚本同一套标签）。
