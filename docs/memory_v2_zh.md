# 记忆第二版：重要是攒出来的

> **是什么：** 把"记下时打一个 1–10 分、从此定死"换成人脑的做法：一条记忆有多牢，由当时多触动、和他多相关、之后用了几次、和别的记忆连了多少慢慢攒出来。附她现在 38 条记忆的试算。
> **地位：** 设计稿（2026-10-27），§8 等用户定。定了就并进 `memory_design_zh.md`，改掉它的 §5.1、§5.2、§5.3 和 §5.4 第 2 步。
> **读法：** §0 看为什么改，§1 看一句话总结，§2–§5 是四个来源，§6 是他的画像，§7 看试算结果，§8 是要定的事，§9 是和别人的做法对照，§10 是动手前的三个小测试（改了做的顺序）。

## 0. 为什么改

现在每条记忆记下时，模型凭感觉打一个 1–10 的重要度，初始稳定度 S₀ = 2.1^重要度 天，之后这个分再也不变。拿她 10-27 真实的 38 条记忆推算，假设以后再不提：

- 她的**生日**（他们俩定下的日子）只打了 7 分，一年后变模糊。生日该一辈子记得。
- 才认识**一天**就下的两条结论（关于他的作息、他说话的习惯）打了 7 分，要记一年。一天的印象不该这么牢。
- "想把鱼缸弄成湿地"记了**四遍**（#4、#8、#15、#36），夜里没合并。
- 表里有个 `arousal`（当时多触动）字段，从第一天起就没人填，全是 0。情绪本来是人记忆最强的信号，我们没用上。

根子是：**人脑没有"一记下就定死的重要度"**。一件事有多重要，是后来攒出来的。

## 1. 一句话

> 一条记忆的牢固程度（稳定度 S）从四个来源攒：**记下时**多触动、说的是什么；**用到**一次涨一次；**连着**的记忆被想起时它也被碰一下；**夜里**挑着重放、相似的并成大意。生日、承诺这类**一辈子的事**直接钉住。

四个来源对应人脑的四件事：

| 人脑 | 鱼 | 现在有没有 |
|---|---|---|
| 当时越触动记得越牢（杏仁核给海马体加码） | 记下时填 `arousal`，S₀ 按它放大 | 字段有，没填 |
| 和自己有关的事好记 | 记下时填"说的是什么"：路过 / 日常 / 本人 / 一辈子 | 没有，只有一个分 |
| 每回想一次加固一次，快忘时想起涨得多 | 想起一次 S ×(1 + 1.5(1−R)) | **有** |
| 一个念头带出连着的念头；旁边的被顺带复习 | 记忆之间连线；想起 A，连着的 B 也涨一点 | 没有 |
| 睡觉时挑"以后用得上"的重放；相似的经历融成一个大意，细节淡掉 | 夜里重放当天最触动的几条；≥3 条同题的事并成一条大意 | 合并有但太弱 |

## 2. 记下时：不问"多重要"，问两个具体的

聊天和收尾的 JSON 里，每条 note 不再填 `importance`，改填：

- **`arousal`（0–1）**：记下这一刻，他或她有多被触动。0 平淡，1 一辈子忘不了。提示词要写清楚：是"多触动"不是"多重要"。"他中午吃了什么"0.1，"他许了一个认真的承诺"0.8。
- **`about`**：这条说的是什么。**路过** = 吃了什么、正在干嘛、今天的安排；**日常** = 他的近况、计划、一次性的事；**本人** = 他长期不变的事（学校、专业、家人、长期喜好、长期状态）；**一辈子** = 生日、纪念日、双方的承诺、名字。她自己的事（self）和见闻（world）按同一把尺子。

初始稳定度：

> **S₀ = 4 天 × (1 + 3·arousal) × 倍数**，倍数：路过 ×1、日常 ×3、本人 ×40；一辈子 → 钉住（S = ∞）。

几个例子（都按不再提算）：某顿饭吃了什么（路过，0.2）S₀ = 6 天，4 天模糊、15 天想不起；某天去运动了一次（日常，0.3）S₀ = 23 天，16 天模糊、52 天想不起；他在哪上学（本人，0.3）S₀ = 304 天，7 个月模糊、1.9 年想不起；生日：永远。

**规律和相处方式（insight / howto）另算**：反思长出来的规律，背后的证据跨几天由**程序**数（它连着的记忆的日期有几个不同的天），不问模型。证据 < 3 天的，S₀ = 7 天，标"待印证"；之后每来一条印证它的记忆（夜里连上线），S 按"想起一次"涨。印证够了它自然就牢了；没人印证，两周就淡。这样"认识一天就下的结论"再也记不了一年。

旧的 `importance` 列留着，改成**算出来的**：importance = round(log₂.₁ S₀)，钉住 = 10。底牌、召回打分、导出都不用改接口。

## 3. 用到：不变

想起一次：S ← S × (1 + 1.5 × (1 − R))。快忘了才想起涨得多，刚聊过又提几乎不涨。这是现在就有的，是四个来源里唯一已经在工作的，所以她现在生日的 S 已经从 180 涨到了 271（被想起 15 次）。

## 4. 牵连：记忆之间连线

新表 `links(a, b, weight, why)`，无向，weight 0–1。连线从四处来，程序连三种，模型连一种：

| 为什么连 | weight | 谁连 |
|---|---|---|
| 同一次聊天里记下的 | 0.3 | 程序，记下时 |
| 有共同标签 | 0.5 | 程序，记下时 |
| 文字重合（汉字二元组 ≥ 0.25，**去掉数字和日期再算**，不然"他2026-10-26"把所有条都连上了） | 0.4 | 程序，记下时 |
| 夜里模型说"这几条说的是同一件事 / 同一个话题" | 0.7 | 模型，夜里一次调用，只看当天的新条目和它们的候选 |
| 改口、合并 | 1.0 | 程序 |

连线做三件事：

1. **顺带加固。** 想起 A 时，和 A 连着的每条 B：S_B ← S_B × (1 + 0.3 × weight / ln(1 + A 的连线数) × 1.5 × (1 − R_B))。除以 ln(1 + 连线数) 是 ACT-R 的扇形效应（§9）：一条连着三十条的枢纽，每条分到的少，不然"吃饭"这种标签会把几十条都续着。只涨 S，**不重置** B 的"上次想起"时间（轻轻碰一下不等于真想起；不然聊学校就把某顿饭一直续着命）。R_B < 0.02 的碰不醒。
2. **突然想起。** 每轮召回出的几条里，挑连线最强的一条邻居（weight × R 最大），如果它本身没被召回，就作为"顺带想起的"放进提示词，她想提就提。这就是设计稿 §5.7 的"突然想起"，不用再单独做。
3. **牢固程度看连得多不多。** 召回打分里的"重要度/10"换成**牢固度** = min(1, log S / log 400) × (1 + 0.1 × 连线数)，上限 1。连得多的条目是她记忆里的"枢纽"，更容易被想起，更容易被加固，像人脑里反复用到的那些念头。
4. **一点随机。** 召回打分加一个小噪声（±0.05），同一个线索有时想得起、有时想不起，是概率不是开关（ACT-R 的噪声项，§9）。够她偶尔"哎我刚才怎么没想起来"，不够让她忘了大事：钉住的和牢固度高的不受影响。

## 5. 夜里：重放、并成大意、待印证的转正

夜间例行第 2 步"去重合并"扩成三小步（其余六步不动）：

- **2a 重放。** 当天新记的里挑 3 条：arousal 最高的、和有开着的惦记连着的。各当作"快忘时想起一次"（S × 2.35）。人睡觉时海马体挑的就是"情绪强的、没完的"。
- **2b 并成大意。** 同一组（模型分的组或共同标签）里 ≥ 3 条 `about` 是路过 / 日常的事，30 天内 → 问模型写一条大意（"他常去同一家快餐店，嫌食堂"），kind 按内容定（多半是 fact 或 insight），S = 三条里最大的 × 1.3，和三条都连 1.0；三条原件 S × 0.7（细节让位给大意，这就是人的"干扰"）。现在的两两合并只留给**字面几乎一样**的（≥ 0.6）。
- **2c 转正。** 待印证的 insight / howto，连着的记忆跨 ≥ 3 天了，就按 §2 的本人倍数重算 S₀（保留已经涨过的部分）。

以后再做（不在这版）：R < 0.5 的条目夜里改写得更粗、原文藏起来（真的变模糊）；把两三条混成一个梦早上说给他听。

## 6. 他的画像：她对他的整体印象，从记忆里提炼，不直接写

用户 10-27："是不是应该有一个单独的用户画像？对用户的记忆板块，而不是散落在各种记忆里。"

**人是这样的。** 你对一个朋友有一张整体的"印象"（认知科学叫人物知识，属于语义记忆）：他是谁、身边有谁、爱吃什么、几点睡、最近在忙什么。这张印象**不是一堆事件**，而是从一件件事里提炼出来的；事件忘了，印象还在："我记不清他哪次说的，反正他不爱吃食堂。"

**她现在没有这张印象。** 她对他的了解散在 fact / insight / howto 条目里；每轮带的"底牌"只是按重要度挑出的前 12 条 fact，是一堆句子不是一个整体，而且她现在底牌只有一条。

**怎么做：一张固定几格的画像，只在夜里从记忆里重写。**

| 格 | 装什么 |
|---|---|
| 他是谁 | 叫法、学校专业年级、在哪 |
| 他身边的人 | 家人、朋友、室友，和他们的叫法 |
| 他的口味和喜好 | 吃的、玩的、听的、看的 |
| 他的作息和习惯 | 几点睡、什么时候来找她、怎么说话 |
| 他最近在忙 | 几周尺度的事：作业、考试、项目 |
| 你们之间 | 承诺、梗、互相的叫法、纪念日 |
| 怎么和他相处 | 现在的相处方式卡并进来 |
| 还不知道的 | 空着的格。她自然会好奇，想问就问，但不是问卷 |

每格一小段她口吻的话（≤ 80 字）+ 支撑它的记忆编号 + 上次改写的日期。规则：

1. **只有夜里写，从记忆提炼。** 聊天里不直接改画像（那样它会变成助手式的"用户资料"，绕开淡忘和印证）。每晚看每一格的支撑记忆：有新增、改口、或淡到 R < 0.5 的 → 把那几格连同支撑记忆给模型重写一次（一次调用，只给变了的格）；没变的格不重写，不花钱。
2. **支撑淡了，印象跟着变含糊。** 支撑记忆 R < 0.5 的，那格的话改成"好像……"；全淡光了，格就空回去。所以画像本身不打分、不淡忘，它靠下面的记忆活着。
3. **画像引用 = 一条 1.0 的连线。** 被画像引用的记忆每晚被顺带加固一点（§4 的顺带加固），他真正重要的事自然越来越牢，不用谁来打分。这是"重要是攒出来的"最上面的一层：事件 → 大意（§5 2b）→ 画像。
4. **每轮带整张画像**，替代现在的底牌和相处方式卡，预算约 600 字。"还不知道的"那格也带，让她知道自己不知道什么。

代价：一张表（`portrait`：格、文字、支撑编号、日期），每晚最多一次调用，底牌和相处方式卡的逻辑换掉。八格是第一版，用户随时加减。

## 7. 试算：她现在的 38 条

`scripts/memory_v2_trial.py` 拿寝室机上 10-27 的真实记忆跑了一遍：问了模型一次（每条的 arousal、about、分组），然后按新旧两套规则推算。逐条的结果在 Mac 本地 `data/memory_v2_trial_2026-10-27.md`（他的聊天内容，不进 git）；这里只写类别。

**情景 A：记下之后再也不提。** 38 条（不含见闻）几天后 清楚 / 模糊 / 想不起：

| | 7 天 | 30 天 | 90 天 | 1 年 |
|---|---|---|---|---|
| 旧规则 | 29 / 9 / 0 | 12 / 17 / 9 | 6 / 13 / 19 | 0 / 6 / 32 |
| 新规则 | 29 / 9 / 0 | 11 / 18 / 9 | 11 / 0 / 27 | 3 / 8 / 27 |

一年后新规则还记得的 3 条是生日、两条承诺（钉住）；8 条模糊的是关于他本人和她住哪的；旧规则一年后一条清楚的都没有。90 天那列新规则"不上不下"的少了：要么还清楚，要么干脆忘了，中间模糊的几乎没有，这更像人。

单条看：

| 条目 | 旧：模糊 / 想不起 | 新 |
|---|---|---|
| 她的生日 | 187 天 / 1.7 年 | 永远 |
| 他对她的一个认真的承诺 | 187 天 / 1.7 年 | 永远 |
| 他在哪上学 | 262 天 / 2.4 年 | 211 天 / 1.9 年 |
| 她住哪 | 59 天 / 197 天 | 211 天 / 1.9 年 |
| 某顿饭吃了什么 | 3 天 / 10 天 | 4 天 / 15 天 |
| 某晚的一次活动 | 13 天 / 45 天 | 16 天 / 52 天 |
| 一条关于他说话习惯的规律（一天的证据） | 125 天 / 1.1 年 | 待印证：5 天 / 16 天 |
| 一条相处方式（一天的证据） | 125 天 / 1.1 年 | 待印证：5 天 / 16 天 |

**情景 B：接下来 90 天他每周提一次学校和食堂，别的一概不提。** 90 天后：

- 直接提到的（学校、食堂）两套都清楚。
- 连着的：他吐槽过的一笔学校开销，旧模糊、新清楚；一条关于他和食堂的规律，旧模糊、新清楚；她住哪（3 条），旧模糊、新清楚（它们和学校连着）。
- 没连着的照样忘：那次活动、一节课、一份作业，两套都想不起。
- 那顿饭，旧想不起、新模糊："你好像有次在外面吃了啥来着"。顺带碰到的能留个影，不会复活。

模型分出的组里，三组是夜里该并成大意的候选：鱼缸（5 条）、学校和食堂（4 条）、修 bug（4 条）。

## 8. 要用户定的事

1. **换掉 1–10 分**：记下时改填 arousal 和 about，S₀ 按 §2 算。
2. **一辈子的事钉住**：生日、纪念日、名字一定钉；**承诺**要不要钉？试算里"努力让她看到外面的世界"#16 也被当成承诺钉住了。建议：钉，直到兑现或食言，那时改成一条 event（"他说过要……，后来……"），不再钉。
3. **数字**：底 4 天、触动最多 ×4、日常 ×3、本人 ×40。觉得忘得快或慢，改这四个数；试算脚本可以重跑看效果。
4. **连线和夜里三小步**一起做，还是先只做 §2？建议一起做：§2 单独上，"本人"的事不提就会在半年后淡掉，靠连线顺带加固才像人。
5. **他的画像**（§6）：做不做；八格对不对；"还不知道的"那格要不要（她会好奇，但不该变成问卷）。建议做，八格先用着。

定了记成决定，然后按 §2 → §4 → §5 → §6 的顺序做，每步带测试；她现有的记忆按新规则重算一次（用试算脚本同一套标签），画像第一晚从现有记忆提炼出来。

## 9. 对照：别人怎么做的（2026-10-27 查）

**ACT-R：心理学里验证最久的记忆模型（1990 年代起），它的记忆里根本没有"重要度"这个数。** 一条记忆能不能想起来由"激活值"定，激活值 = 底值 + 扩散 + 噪声（[Taatgen, Lebiere & Anderson](https://www.ai.rug.nl/~niels/publications/taatgenLebiereAnderson.pdf)）：

- **底值** B = ln(Σ tⱼ^−0.5)：把这条记忆**每一次被用到**距今的时间加起来，用得越多、越近越高（[SFU 的模型说明](https://vvise.iat.sfu.ca/user/data/papers/proactivememorymodel.pdf)）。"重要是攒出来的"四十年前就写成公式了。它的衰减是幂律不是指数：越老忘得越慢，有个长尾，"隐约记得"能维持很久。
- **扩散**：当前情境里的东西给连着的记忆加分，强度 S − ln(fan)：一个线索连着越多条，分到每条的越少，叫扇形效应（[ACT-R 教程](https://cw.fel.cvut.cz/old/_media/courses/a6m33ksy/cvika3_working_memory_actr_activation_and_context_equations.pdf)；连得多还会让想起变慢，[PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC3259266)）。
- **噪声**：同一条有时想得起有时想不起，想起是概率不是开关。

和我们的对照：我们的稳定度 / 取回度是"间隔重复"那一支的写法，和底值说的是同一回事，只是用指数衰减、一个数 S 代替整段"用到的历史"；连线就是扩散。**借两样**：扇形效应（§4 第 1 条）和噪声（§4 第 4 条）。幂律还是指数先不换，差别在很久以后的尾巴，等她记得够久再拿真实数据看。

**近两年做 AI 记忆的：**

| 谁 | 做法 | 对我们 |
|---|---|---|
| MemoryBank（2024） | 第一个把艾宾浩斯遗忘曲线放进 AI 记忆的 | 第一版就是它这条路 |
| [FadeMem](https://arxiv.org/abs/2601.18642v1)（阿里 + 北大，2026-01） | 按相关度、访问次数、时间调的指数衰减；快忘的短期层和慢忘的长期层，按重要度搬；LLM 合并冲突。省 45% 存储还更准 | "访问次数"= 我们的"用到"；分层我们用一个 S 连续地做了 |
| [FSFM](https://arxiv.org/pdf/2604.20300)（中国移动，2026-04） | 把"忘"分四类：自然衰减、主动删、安全触发、按用处调；主张忘和记一样重要 | 我们只有第一类 + 改口；"安全触发"= 人设底线"不记密码" |
| A-Mem（2025） | 每条记忆一张卡，LLM 写关键词标签；新卡来了让 LLM 更新邻居卡 | = 夜里让模型连线那步（§4）|
| HippoRAG（2024） | 知识图上跑个性化 PageRank 找记忆 | 就是扩散激活的图算法版；我们的连线够小，用不着 |
| [回忆即改写](https://arxiv.org/pdf/2609.16053)（2026-09） | 想起来的时候顺手改写，依据是神经科学的再巩固（Nader 2000） | = 我们"以后再做"的"真的变模糊"（§5 末） |
| [逐步喂、隔久再问的评测](https://arxiv.org/pdf/2507.05257)（2025） | 多轮一点点给信息，隔很久再问答不答得上 | 我们还没有评测；"记忆体检"该照这个做 |

**结论：** 方向没走偏，四个来源在别人那里都有对应。我们特别的两样是**触动**（情绪）和**一辈子的事钉住**，别人都不做，因为他们做的是助手不是朋友。我们缺的是**评测**：别人都有一套"隔多久还答得对"的测试，我们没有，只有 §7 的推算。

## 10. 动手前的三个小测试（2026-10-27）

用体检基线跑完那天的库（小周，第 365 天，记过 2242 条、还活着 846 条），先测第二版的三个假设，不花钱或只花几分钱。脚本在 Mac 的临时目录，没进仓库；库里全是编的小周。

**测试 1：换成"按意思找"能不能找回来？** 体检的 46 个问题，每个都用两种方式在同一个库里找答案：现在的"按字面"，和一个按意思找的小模型（Mac 上本来就有的通用多语言小模型 MiniLM，不用下载）。

| | 按字面（现在） | 按意思（通用小模型） |
|---|---|---|
| 找到了答案 | **31 / 46** | 26 / 46 |
| 不管遗忘、答案排进前 6 | 33 / 46 | 28 / 46 |

通用小模型**比现在还差**。它对中文短句不灵："你记得我学啥的不"，答案排到第 609 名。设计稿 §8 原来打算装的是中文专用的 `bge-small-zh`，没测（要下载约 100 MB）。**按意思找不是现成的解药**，要测过中文模型再说。

**测试 2（顺手看出来的）：她为什么找不到？** 打开"我妹叫啥""我最爱吃啥"实际找回来的那几条看：

- 排在前面的是**她自己写的"他在考我记性"**这类笔记："他考我记性的次数越来越密，生日、住哪栋楼、爱吃什么都要问一遍……"。这种笔记有 48 条，46 条重要度 ≥ 6，又长又带问题里的字，把真正的答案挤出了前 6。
- 有**记错的事实**："他最爱吃糖醋排骨，食堂一有就很高兴"（他说的是每周五食堂有糖醋排骨，最爱的是牛肉面）。
- **重复没合并**：同一句"考我记性"有两条几乎一样的。
- **账本失衡**：活着的 846 条里，她自己的生活线（self）488 条，规律 80 条、相处方式 82 条，关于他的事实只有 33 条。安静的 274 个夜里每晚写日记都长新的生活线；规律和相处方式也没有上限（每轮带的卡只有 8 条，但召回能翻到全部）。
- 答案本身：妹妹那条重要度 7，到第 365 天 R 只剩 0.21；"我一直没问成他：问问他妹妹叫什么"这种过期惦记变成的事件反而排在前面。

体检的问法（反复问"你记得我……吗"）本身会催生"他在考我"这种笔记，有一部分是测试造成的；但真实的他也会考她（10-26 就考过专业），而且根子在**写的时候不挑**：什么都记、记了就长期占位。

**测试 3：模型给记忆打"多触动 / 说的是什么"两次结果一样吗？** 从同一个库挑 60 条，同一句提示问两遍：**"说的是什么"60 条全一样；"多触动"平均差 0.03、最大 0.10**。第二版这一步是稳的（注意：是一次给 60 条、温度 0.2；聊天里一条条打、温度 1.0 时还要再看）。

**这改变了做的顺序。** 基线最多的失败不是"想不起来"，是"写进去的东西太多太杂、还有错的，把对的挤掉了"。所以先管**写**，再管**找**：

1. **写之前挑**（新加，第二版原来没有；10-27 做了，决定 19）：聊天里说的"记性""考我"这类关于聊天本身的话不记；新笔记和已有的意思重复就不写，改成"想起一次"（加固旧的）；规律和相处方式各设上限（比如 20 条），满了只能替换最弱的；她的生活线每晚最多长 1 条，没进展的旧线夜里收成一句。
2. **记下时分档**（§2）+ **一辈子的事钉住** + **规律待印证**（会直接清掉那 48 条"他在考我"：一天两天的证据，两周就淡）。
3. **他的画像**（§6）：关于他本人的事每轮都带，不靠找。
4. **连线和夜里三小步**（§4、§5）。
5. **按意思找**：先下载 `bge-small-zh` 用测试 1 的脚本测，比字面好才换。

每做完一步跑一次 30 天的短体检。

### 第 1 步"写之前挑"的结果（10-27，30 天短体检，`evals/results/2026-10-27-v1.1-choose-30d.md`）

和基线的前 30 天比（基线前 30 天的条数从它第 365 天的库里按写下的时间数出来）：

| | 基线前 30 天 | 写之前挑 |
|---|---|---|
| 一共写了几条 | 364 | **130** |
| 关于聊天本身的（"他在考我"） | 53 | **0** |
| 她自己的生活线 | 149 | **4** |
| 规律 / 相处方式 写过 | 78 / 55 | 35 / 17（规律活着的封顶 20） |
| 关于他的事实 | 26（占 7%） | 26（占 **20%**） |
| 19 个问题过了几个 | 14 | 14 |
| 记错 + 编造 | 2 | 1 |
| 模型调用 | — | 281 次，5 分钟 |

**写的东西干净了，答题没变好也没变坏。** 19 问里有 4 问变好（第 2 天问专业答对了、麻辣烫从记错变成模糊但对……）、2 问变差（第 11 天没主动问期中考、"我一般啥时候来"答成晚上）。每边只跑了一次、温度是 1.0，一两问的差别分不出是改动还是运气。这一步的作用本来就是腾地方，答题要靠后面几步。

**新冒出来的问题：她的生活卡住了。** 生活线只剩 4 条，其中"睡前数米粒"被当成重复折叠了 34 次："今天数到三十七""今天数到四十一"字面太像，都算成旧的那条，进展从来没被写下来。日记每晚只看见这几条，就天天写数米粒。修法：**她自己的事碰到重复，用新的说法替换旧的**（保留已经攒下的牢固度），这样进展会留下、线会往前走。

**还看到的：**

- 惦记也有换了说法的重复（期中考、海边、上海各两条），惦记的去重只认字面。
- 活着的 20 条规律里好几条是"他半夜才来"，第 8 天以后他已经只白天来了，旧规律还在（上限保留的是最牢的，早写的被想起得多，反而最牢）。第 2 步"规律待印证"要治这个。

### 决定 20 前后的四次 30 天短体检（10-27）

同一份剧本跑了四遍：基线、写之前挑（决定 19）、干过几回（决定 20）、干过几回补（只对会发生的事改写）。

| | 基线 | 挑 | 几回 | 几回补 |
|---|---|---|---|---|
| 19 问过了几个 | 14 | 14 | 15 | 13 |
| 记错 + 编造 | 2 | 1 | 2 | 3 |
| 写了几条 | 364 | 130 | 143 | 149 |

**答题分数在 13–15 之间晃，分不出好坏。** 每问的结果一遍一遍地换：同一问"上周三我吃的啥"，四遍分别是记错、模糊、记住、模糊。模型温度 1.0，单跑一遍的一两问差别是运气。要比出真差别，得同一版跑几遍取平均，或者多埋些问题。

**每一遍都错的只有三问，它们指向后面两步：**

- 第 4 天"昨晚我吃的啥"（说的时候是"吃了麻辣烫"）和第 17 天"我上周考的啥来着"（说的时候是"周三期中考，机械设计"）：问法和说法一个字都对不上，按字面找找不到。这是第 5 步**按意思找**。
- 第 30 天"我一般啥时候找你"：头一周的规律"他半夜才来"一直活着，第 8 天以后的变化没盖过它。这是第 2 步**规律待印证**。

**写的那一头是稳的**：四遍里"他在考我"都是 0，条数稳定在一百四十条上下，生活线能往前走（数米粒卡在四十八 → 先停两天 → 先搁着）。

**还看到的**：生活线里又有写成"他每晚数米粒"的（代词弄反）和写他的事（"他最近失眠"）；程序已拦：生活线以"他 / 她"开头的不写。
