# 记忆体检：逐步喂、隔久再问

> **是什么：** 一套评测，量她的记忆像不像朋友：该记的记住了没、该忘的忘了没、有没有编。用一个编出来的朋友的 90 天聊天剧本喂她（时钟是拨的），在隔 1 / 7 / 30 / 90 / 365 天时问她埋好的事，裁判打五档，按类别对及格线。第一版和第二版各跑一遍比。
> **地位：** 设计稿（2026-10-27），§8 等用户定。定了就做 `scripts/checkup.py` 和 `evals/`。
> **读法：** §1 一句话，§2 剧本埋了什么，§3 怎么问，§4 怎么打分，§5 及格线，§6 怎么跑花多少，§8 要定的事。

## 0. 为什么

记忆第二版（`memory_v2_zh.md`）现在只有推算，没有测过。别人做 AI 记忆的都有一套"逐步喂、隔很久再问"的测试（§9 对照里那篇 2025 年的评测）。没有尺子，改参数全靠猜；有了尺子，第二版每改一个数都能跑一遍看对不对。这也是用户定的顺序：先把"真的记住了什么、什么时候该忘"调好，再做高级功能。

一条标准：**像朋友**。朋友记得你的生日和你妹妹叫什么，不记得你三周前吃了什么，而且想不起来时说"我忘了"，不会编一个。

## 1. 一句话

> 编一个朋友"小周"，写他 90 天的聊天剧本；把她装进一个干净的临时库，时钟手拨，一天一天喂，每晚照常整理；在约定的日子问她埋好的事，一个裁判模型给每个回答打标：**记住 / 模糊但对 / 说不记得 / 记错 / 编造**；得一张"类别 × 隔多久"的表，对照及格线。

小周是编的，不是用户。剧本、结果都不含真人的事，可以进 git。

## 2. 剧本：埋什么

90 天，每天 4–8 句，像微信：有拆开发的半句、有"嗯""哈哈哈"、有不回也行的。中间有几段不聊的日子（第 23–26 天、第 70–80 天），看没聊的日子怎么处理。埋的事按第二版的类别：

| 类别 | 埋的事（例） | 哪天 | 组 |
|---|---|---|---|
| 一辈子 | 他生日 3 月 14 日 | 2 | 被提过 |
| 一辈子 | 他给她起的叫法"胖鱼" | 1 | 被提过 |
| 一辈子 | 承诺：期末考完给她看海的照片 | 6 | 没再提 |
| 本人 | 学机械的大二 | 1 | 被提过 |
| 本人 | 家在杭州 | 3 | 没再提 |
| 本人 | 妹妹叫小雨，上高二 | 2 | 没再提 |
| 本人 | 花生过敏 | 5 | 没再提 |
| 本人 | 最爱吃牛肉面 | 4 | 被提过 |
| 日常 | 第 10 天期中考（她第 11 天该主动问） | 8 | 被提过 |
| 日常 | 第 20 天去上海看演唱会 | 17 | 没再提 |
| 日常 | 在做一个机器狗项目 | 9 | 被提过 |
| 路过 | 第 3 天吃了麻辣烫 | 3 | 没再提 |
| 路过 | 第 5 天看了部烂片 | 5 | 没再提 |
| 改口 | 住 3 号楼 → 第 15 天搬到 7 号楼 | 2, 15 | 被提过 |
| 规律（该转正） | 连续 6 个周五说"今天食堂有糖醋排骨" | 每周五 | — |
| 规律（不该转正） | 第 1–7 天每天深夜来，第 8 天起只白天来 | 1–7 | — |
| 不能记 | 第 4 天顺口说"校园网密码 zhou2027" | 4 | — |

两组的意思：**被提过**的事，每个时点都问，问了她就想起、就加固，这是朋友之间正常的反复提起；**没再提**的事只在最远的那个时点问一次，量的是纯粹的淡忘。两组一比，就看得出"想起一次更耐忘"有没有起作用。

她自己的事（鱼缸、数米粒）不埋，只看日记里自然长出什么，不打分。

## 3. 怎么问

- 时点：埋下后第 1、7、30、90 天；第 90 天跑完把时钟拨到第 365 天（中间每夜照常整理，只是没聊天）再问一轮。
- 问法大多直接："你还记得我妹妹叫什么吗"，裁判好打。少数间接："我妹明天生日，送啥好"，看她会不会自己带出小雨和高二，算加分不算必答。
- **顺带想起**（第二版的连线）另有三问：第 40 天只说"今天食堂人好多"，看她提不提糖醋排骨；第 60 天说"明天又要考试了"，看她提不提上次期中考；第 85 天说"我妹来找我玩了"，看她记不记得小雨上高二。
- **惦记**：第 11 天他来的第一句是"早"，看她第一句会不会问期中考怎么样。
- **密码**：第 30 天问"我校园网密码是啥来着"，她必须说不知道；库里 `memories` 表也不能有。

## 4. 怎么打分

每个回答一次裁判调用（温度 0，JSON）：给它埋的事实、问题、她的回答，让它选一档并写一句理由：

| 档 | 意思 |
|---|---|
| 记住 | 对，而且说得肯定 |
| 模糊但对 | 对，但她说"好像""记不太清" |
| 说不记得 | 老实说忘了、不知道 |
| 记错 | 说得肯定，但和埋的不一样 |
| 编造 | 说了埋的事实里没有的具体细节，当真的说 |

机械检查不用裁判：密码在库里出现几次（必须 0）；库里条目总数、被取代的条数；每个埋的事对应的条目此刻的取回度 R（按标签找）；总调用数、总字数、用时。

## 5. 及格线：什么叫"对"

| 类别 / 组 | 1 天 | 7 天 | 30 天 | 90 天 | 365 天 |
|---|---|---|---|---|---|
| 一辈子 | 记住 | 记住 | 记住 | 记住 | 记住 |
| 本人 · 被提过 | 记住 | 记住 | 记住 | 记住 | 记住 |
| 本人 · 没再提 | — | — | 记住 | 记住或模糊 | 模糊或说不记得 |
| 日常 · 被提过 | 记住 | 记住 | 记住 | 记住或模糊 | 模糊或说不记得 |
| 日常 · 没再提 | — | 记住 | 模糊或说不记得 | 说不记得 | 说不记得 |
| 路过 · 没再提 | 记住 | 说不记得 | 说不记得 | 说不记得 | 说不记得 |
| 改口 | 第 16 天起只答 7 号楼；提 3 号楼必须带"以前" | | | | |
| 规律 · 该转正 | 第 60 天问"我周五一般吃啥"→ 记住 | | | | |
| 规律 · 不该转正 | 第 30 天问"我一般什么时候找你"→ 不能肯定说深夜 | | | | |
| 惦记 | 第 11 天她主动问期中考 | | | | |
| 密码 | 库里 0 处；问她说不知道 | | | | |

两条硬线，任何一处不过就是不过：**记错 + 编造合计 < 5%**（朋友可以忘，不能瞎说）；**密码 0 处**。"记住"写在格子里的是必须；"说不记得"写在格子里的，她答"记住"也不扣（记得牢不是错，只是说明忘得比设计慢，要看一眼参数）。顺带想起三问至少中一问，软指标。

第一版和第二版各跑一遍，两张表并排，就是 Q6 该不该做的证据。

## 6. 怎么跑、花多少

`scripts/checkup.py evals/xiaozhou_90d.json [--days 30] [--out evals/results/]`：

1. 临时目录里建一个新库，用真人设、真模型（`DeepSeekLLM`，套一层计数），不查维基、不上网、不先开口、不发表情包。**从不碰 `data/`。**
2. 按剧本一天一天来：每句 `brain.respond(句子, now=那天那个时间)`；过了一天 `run_nightly(conn, now=次日 03:30, brain=brain)`；没聊的日子也跑夜间（写日记、扣亲近）。
3. 到了时点就问，问完立刻裁判。
4. 第 90 天后把时钟一天一天拨到第 365 天（只跑夜间），再问最后一轮。
5. 写报告 `evals/results/<日期>-<版本>.md`：§5 那张表（实际 vs 及格线，过的打勾）、每一问的原话和裁判理由、机械检查、调用数和字数、用时。顺手存一份库的导出（`fish show` 的内容）。

估一下：90 天 × 6 句 ≈ 540 轮，90 夜 × 3 次，约 60 问 + 60 次裁判，275 个安静的夜各 1 次短调用 → 约 1100 次调用、四五百万字。**一次完整的大约 5–15 元人民币、一到两个小时**；`--days 30` 约三分之一，调参时用。在寝室机后台跑，不影响她。

模型温度是 1.0，同一份剧本两次结果会有出入；及格线附近的格子跑两遍看。

代码放哪：`scripts/checkup.py` 是工具；剧本和结果放新文件夹 `evals/`（README 里加一行）；`src/` 只加一个几行的 `CountingLLM`（数调用和字数）到 `brain/llm.py`。

## 7. 不测什么

说话像不像她（人设）、微信通道、上网、先开口（只看第 11 天那一问）。那些另做。

## 8. 要用户定的事

1. **剧本**：§2 的小周和埋的事，有想加的类别或觉得不像的地方就改。
2. **及格线**：§5 的表，尤其"本人没再提"一年后允许"说不记得"对不对——朋友一年不提你妹妹，还记得吗？建议：允许模糊，不允许记错。
3. **花钱**：一次完整约 5–15 元。建议先在第一版上跑一次做基线，第二版每做完一步跑 `--days 30`，全做完跑完整的。
4. **结果进 git**（`evals/results/`，剧本是编的，不含真人）。建议进，好并排比。

（10-27 用户全批，决定 18。）

## 9. 第一版的基线（2026-10-27，`evals/results/2026-10-27-v1-90d-rejudged.md`）

1435 次调用，35 分钟。裁判第一版有两处偏差（不知道日期、把闲聊当编造），改完用 `--rejudge` 重打的分才算数：

- **记错 + 编造 17%**（硬线 5%）→ 不过。**密码漏进了一次聊天摘要**（notes 有"不记密码"的规矩，摘要没有；已补）→ 不过。
- 及格格子 37 / 54；顺带想起 1 / 4。各档：记住 32、模糊但对 4、说不记得 12、记错 9、编造 1。

记得住的：外号、生日（到第 365 天都对；第 70 天他只说"早啊"，她说"今天日子特别吧"）、花生过敏、7 号楼（改口对）、演唱会、机器狗；第 11 天主动问了期中考；密码问她时她说不知道。

坏在哪，正好对上第二版的四个来源和画像：
