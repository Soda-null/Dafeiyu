# `docs/` 索引

> **是什么：** `docs/` 下每份文件是什么、地位是什么。
> **地位：** 索引。新增、移动或改名 `docs/` 下的文件，同一次提交改这里（`scripts/check_doc_structure.py` 查）。
> **读法：** 查表。

四种地位：**现行**（规定现在的工作）、**账本**（只追加）、**索引**（只列文件）、**规程**（怎么用工具）。

| 文件 | 地位 | 是什么 |
|---|---|---|
| `architecture_zh.md` | 现行 | 鱼怎么搭：七个模块、一条消息怎么流、数据存在哪、建造顺序 |
| `memory_design_zh.md` | 现行（设计稿，§11 等用户点头） | 记忆机制全文：学人的哪些机制、条目长什么样、记下 / 想起 / 淡忘的数学 / 夜间整理 / 改口、每轮流程、代码架构、数据表、验收 |
| `memory_v2_zh.md` | 设计稿（§7 等用户定） | 记忆第二版：重要不是记下时打的分，是从触动、相关、用到、牵连、夜里重放攒出来的；附她 38 条真实记忆的试算 |
| `world_design_zh.md` | 现行（设计稿，§7 等用户点头） | 她怎么上网看世界：每天逛一次挑几条、聊天里查一下、见闻是第六种记忆、防网页里的坏话、代码放哪 |
| `persona_zh.md` | 现行 | 大肥鱼是谁：性格、说话方式、习惯、故意的不完美、底线 |
| `decisions.md` | 账本 | 定下的事，一条一个日期；推翻要加新条目 |
| `open_questions.md` | 账本 | 还没定的事，标 ● 的要用户定 |
| `glossary_zh.md` | 索引 | 每个项目代号一行人话 |
| `writing_guide_zh.md` | 现行 | 文档怎么写、放哪、三行卡片 |
| `box_zh.md` | 规程 | 她常驻在寝室 Ubuntu 机上：部署、看日志、重扫码、备份、出了事怎么办 |
| `log/` | 账本 | 每个工作日一个文件：做了什么、下一步 |
