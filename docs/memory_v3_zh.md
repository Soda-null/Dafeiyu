# 记忆第三版：在第二版上打补丁

> **是什么：** 记忆第三版的整套设计：不推倒重来，在第二版上修几个确定的 bug，把承诺和外号钉住，日子由程序算好，考试结果挂回原来那件事，允许翻聊天摘要，路过的小事忘得快。附量具（体检剧本第 2 版、两个离线脚本）和 2026-10-27 量的基线。
> **地位：** 设计稿（2026-10-27），接着 `memory_v2_zh.md` 往下做，在 `memory-v3` 分支上一步一步实现。要用户定的事在 §11；没点头之前，那几处只在分支上，不上线。做到哪一步在 §12。
> **读法：** §0 一段话看完；§1–§7 是设计，按"存什么 → 怎么记 → 怎么找 → 怎么忘 → 不知道怎么说 → 规律 → 花多少钱"排；§8 搬真实数据；§9 故意不做的；§10 量具和现在的分数；§11 要你拍板；§12 做到哪了。

## 0. 一段话

第三版不推倒重来，在现在的记忆上打补丁，再从另外两份设计里挑几样最好用的接进来。三位评委（看效果、看成本、看风险）打分，"补丁版"平均 7.0 分最高，所以拿它当底子。

主要做六件事：

1. **修确定的 bug。** 比如她找记忆时会把自己上一句话也拼进去，结果"室友"两个字把承诺那条挤出了前 6 名；"按时间找"写好了却一直没接进聊天。
2. **承诺和外号由程序用固定的词去认**，认出来就钉住（钉住 = 永远不淡），每轮都带着。承诺还记"兑现了没"，他一提到相关的词（比如"驾照"），这条排到最前。
3. **"今天几号、周几、是不是他生日、今天有什么安排、他一般几点来、每周五吃什么"全部由程序算好**再告诉她，不让模型自己推。
4. **考试这类事的结果**（"八十来分"）挂回原来那件事上，不再另写一条 7 天就淡的感想。
5. **他问"昨晚、上周"或者"你记得吗"的时候，允许她翻那几天的聊天摘要。** 摘要照现在的规矩越旧越简略，而且从来不翻原话。
6. **路过的小事最多记 14 天**，只有真相关的回想才让记忆变牢，关于他本人的事最多变模糊、不会彻底消失。

每轮、每晚都不多调模型，不多花钱。有四件事要你先点头（§11）：翻摘要、遗忘的几个数字、改她的真实数据、花钱跑体检；另外第 1 步里有一处和决定 17 不一样（过期的惦记不再记成"没问成"），也列在 §11 等你点头。

## 1. 存什么

只在记忆表（`memories`，她记的每一条）上加 5 列，另建一张只给体检看的小表，不建新的记忆表。

- **为什么不再用了**（`why`）：一条记忆被换掉时记下原因：改正、更新、合并、超了上限、过期。只有"改正"和"更新"才会在提示词里显示成"你之前记的是……"。现在合并掉的旧条也会冒出假的"之前记的"，这列修它。
- **事情哪天发生的**（`happened_on`）：和"她哪天记下的"分开存。周五说"周三吃了麻辣烫"，发生日是周三。按时间找先看这一列。
- **结果**（`outcome`）：比如"考得还行，估计八十来分（1/14 说的）"。原来那句话一个字不改。
- **约定**（`pact`）：这条是他答应她的、她答应他的、还是两人说好的；再加一列"还开着 / 兑现了 / 不算了"（`pact_state`）。约定一律钉住、算"一辈子"。用来认它的词（比如"驾照"）放在原有的标签里。
- 惦记（带到期日的"要问他的事"）多记两样：它是从哪条记忆来的、在哪次聊天里问掉的。
- 每次聊天（`episodes`）多一列"这次记下的标签和专名"，收尾时由代码写好，当翻摘要的索引。
- 程序数出来的规律（"周五吃糖醋排骨"）存进现成的关系账里，每条带"还在 / 停了"的状态。"他一般几点来"每轮现算，不存。
- 新表"可能是编的"（`unsupported_detail`）：她回复里出现了提示词里没有的片名、数字、名字，就记一行。只观察，不拦她说话，体检拿它数。

不变的：记忆的六种类型、"说的是什么"四档（路过 / 日常 / 本人 / 一辈子）、聊天原话永远不删、第二版的遗忘公式。

## 2. 怎么记

### 2.1 每轮

她每轮回复时顺手写笔记。提示词把"该记什么"说得更全：

- 事情的**结果**单独记；
- 带名字的小事记成"路过"，菜名、片名、店名原样写；
- 新出现的人写成"名字 + 跟他什么关系"，名字像的人分开写（阿杰和杰哥）；
- 外号写成"他给我起的外号是 X"；
- 硬规矩：嘴上说了"记住了"，笔记里就必须有这一条。**秘密除外。**

"说的是什么"那一档加一句：他答应你的、你答应他的、你们说好的，听着像计划也算一辈子。标签加一句：放具体名字，再放他以后可能怎么问（吃的 / 看的 / 考的），以及会让你想起它的东西（花生过敏 → 宫保鸡丁、花生酱）。

写进库之前，程序再兜几道底（都不调模型）：

- **秘密过滤**（新文件 `memory/scrub.py`）：6 位以上连着的数字，或者一句里有"密码 / 验证码 / 卡号 / 证件"，这条直接不写。笔记、聊天摘要、日记，每个写的地方都过这一道；翻摘要读出来时再过一遍。
- **认承诺**：只认聊天里和收尾时写的笔记（她逛网、夜里整理写的不算）。要同时满足三条：
  1. 有"答应 / 承诺 / 说好 / 说定 / 约好 / 保证 / 发誓 / 一言为定 / 拉钩"，或者"等……就给你 / 带你 / 陪你"这种句式；
  2. 对象是她："给我 / 跟我 / 陪我 / 答应我 / 大肥鱼 / 咱俩"之类，或者她写的"我答应他"；
  3. "答应"后面没紧跟第三个人（"答应室友"不算）。

  满足就设成约定、钉住。每晚的报告里列出所有认出来的，方便查错。
- **认外号**：有"管我叫"，或者有"外号 / 昵称"并且说的是她（"给我 / 叫我 / 我的 / 大肥鱼"之类）的，强制成关于他的事实、一辈子。不认光秃秃的"叫我"（防"他叫我别熬夜"）；"喊我"只在后面紧跟引号里的名字时算（防"他喊我早点睡"）；别人的外号（"他室友外号叫大头"）不算。和认承诺一样，只认聊天里和收尾时写的笔记。
- **长期的事不因"今天 / 最近"降档**：第二版会把带"最近"的句子降成日常，但"我妹最近期中考"里的"妹"是一辈子的事。有"妹 弟 哥 姐 爸 妈 家在 老家 过敏 不耐 不能吃 专业 学校 年级 公司 岗位 生日 最爱 外号 从小 以后"这类词的，不降。
- **重复也能升级**：判成和旧条重复时，新的那档更重要，就把旧条一起升上去。新的里有旧条没有的数字或书名号《》，就另记一条，不当重复。
- **日期校对**：笔记里同时有"周X"和日期、两个对不上时，在前后 3 天内把日期挪到那个周X。

惦记的改动：记下时程序填"从哪条记忆来的"；和约定挂钩的惦记永远不过期；其余照旧宽限 1 天，过期只关掉，**不再写成"我一直没问成他"那种事件**（那些事件把记忆塞满了）。他的生日由"今天"那一节负责（§3.1），不再靠惦记。

### 2.2 一次聊天收尾

- 收尾用的时间改成"这次聊天最后一条消息的时间"，不是夜里整理的时间。
- 看这次全部没压缩的消息，不再只看最后 12 条。
- 多给它看两样："这次你问过他：X"；"最近 30 天里会有结果的事（考试、面试、搬家……），这次提到了的：#22 机械设计期中考（1/13）——他说结果了吗？"
- 它多回两样：结果挂到哪条上、哪个约定兑现了或不算了。代码会核对编号：必须是刚才列给它看的、还活着的那几条。对不上就把结果另记成一条，不硬挂。
- 检查清单加上：结果和分数、带名字的小事、外号、新出现的人、"以前 X 现在 Y"的变化。
- 模型回的 JSON 坏了：把原文当摘要存下，不记笔记，**摘要绝不丢**。

### 2.3 夜里

- **合并**几条成一条时：取几条里最重要的那档；`happened_on`、钉住、约定一起带过去。改正时也带上旧条的档。合并提示词加一句"原来是谁的事就还写谁"，程序再兜一道：她自己的事合并完变成"他……"开头，就放弃这次合并（现在会出现"他数米粒"这种怪条）。
- **回想**（每几天让模型看最近的事、总结看法）：
  - 只能把上次回想**之前**就有的条目标成过时（现在会把新事实冤枉成过时）；相处方式也能被标过时；
  - 加一句"几点来、每周几做什么由程序数，你别写成看法"；
  - 新增"这些编号又被印证了"，让换个说法的同一条规律也能攒证据。
- **数规律**（§6）。

## 3. 怎么找

### 3.1 不用找、每轮都带的

1. **底牌，最多 12 条**（每轮都带给模型的、关于他最稳的事）：钉住的在前，再是安全相关的（过敏、不耐、病、药），再是关于他本人的、按最近一次提起倒排。不再按牢固度排。
2. **约定块，最多 6 条**：还开着的约定全放。他这句话里出现了某条的触发词，就标星放最前："★他刚说到「驾照」——你答应过他：……"。
3. **"今天"那一节**（新文件 `memory/today.py`，纯代码）：
   - 日期表：昨天、前天、本周和下周每一天、下下周二是几号；
   - 底牌上的生日或纪念日是今天或 3 天内，写一行；
   - 发生日是今天或明天的事，写"今天：……"（小林剧本第 23 天出差那种）；
   - 今天正好是某条规律的那个星期几，写一行；
   - 他一般几点来，一行。
4. 到期的惦记最多 2 条，相处方式卡 8 条，都不变。

### 3.2 要找的

- **找的时候只用他这句话。** 只有他这句很短（去掉"啊、吧"这种虚词后不到 6 个字）时，才拼上她上一句。现在每轮都拼，她上一句里的词会把真正要找的挤下去（§10 有数字）。
- 打分还是现在的"按字面"打分，套上"按时间找"（`when.TimeCued`，他说"上周三"就把那几天的事往前排），终于接进聊天。
- 底牌和约定块里已经有的，不占"想起"的 6 个名额。他这句话碰到了底牌上某条，就在那行后面标"（他这句话提到了）"。另配一张很小的过敏原扩展表，只用来扩展标签：花生 → 宫保鸡丁 / 花生酱；乳糖 → 牛奶 / 奶茶 / 拿铁 / 芝士；海鲜 → 虾 / 蟹。
- **翻摘要（要你同意，§11 第 1 件）：**
  - 什么时候翻：他这句点了一个时间段（"昨晚""上周"），或者在问记忆（记得 / 啥来着 / 叫啥 / 咋样 / 多少 / 哪天 / 几号）。在小周剧本上量过，大约 13% 的轮次会翻。
  - 翻哪几页：按她现在能看到的那一档（30 天内是摘要，30 天以后不重要的只剩一句话要点）加上收尾写的标签来挑。
  - 最多 2 页、每页不超过 160 字，名额和笔记分开算。每页标"【那次聊天的大意，1月8日周五，不是原话】"。
  - **从来不翻聊天原话**：原话里有秘密，也有他贴进来的网页文字，翻出来会被当成"他说过的话"。
- 想起的每一行都写成：`日期（上周三 1月6日）| 来源（你记的 / 聊天大意）| 内容 →结果：…… | 模糊`。"上周三"这种相对日期由代码换算好。同标签的旧事有结果的，带在那一行上（他说"又要考试了"，她能想起上次考了多少）。
- 先不换打分方法。"按名次合票"（各种找法各排一个名次，按名次加起来）和中文意思模型 bge 放到最后一步，可选，达标才接。

## 4. 怎么忘（数字要你批准，§11 第 2 件）

- 起始牢固度的公式不变：路过 4 天、日常 12 天、本人 160 天，再按当时多触动放大；一辈子和约定永远不淡。
- **只有真相关才变牢：** 相关度够高（≥0.3），或者按时间找命中，才算一次"想起"、让牢固度变大。已经在底牌上的不再重复加固。现在随便沾一点边也算想起，麻辣烫这种小事被养到了 128 天。
- **上限：** 路过的最多 14 天；还没印证的看法和相处方式，转正前最多 21 天；现在库里那些"我一直没问成他"最多 14 天。
- **关于他本人的事，能想起的程度最低保持 0.12**：会变模糊（低于 0.5 照样标"模糊"），但不会消失。这只是一条不高的底线，不是永不淡，所以一条写错的本人事实不会永远压着。
- 她自己的事：判重复的线从 0.5 降到 0.35；活着的最多 30 条，超出的标"超了上限"。
- 能想起的程度低于 0.02 的不参加回想，但不删。
- 改口照旧：旧的标作废、不删。收尾时也能改。
- 约定兑现了：那条标成"兑现了"（原话不改，后面带"（兑现了）"），从约定块里拿下来，放上底牌。只有他明说不算了才标"不算了"（不在约定块，也不上底牌，照旧钉住）。

**顺序很要紧：** 这一节必须排在"认承诺、认外号"之后上线。反过来的话，外号和承诺会先被忘掉（审计时回放过一遍，真的会丢）。

## 5. 不知道就说不知道

- 只能根据底牌、约定块、想起的、翻到的那页、"今天"那一节来答；都没有，就说"这个我记不太清了"。
- 不许说"你没跟我说过"，只能说"我不记得你说过"（他可能真说过，只是她没记住）。
- 名字、数字、片名只能照着条目里写的说。
- 他的话和卡上的冲突时，先轻轻指出来（比如"猫是阿杰的吧"）。卡上的人和宠物要写明是谁的。
- 伤心事不猜结局（外婆住院，不能说成去世）。
- 回复发出去后，代码查一遍：回复里的《》、带单位的数字、跟在"叫"后面的名字，既不在提示词里、也不在聊天窗口里，就记进"可能是编的"表。
- 秘密从源头就不写（§2.1）；"说了记住就必须记"那条硬规矩对秘密不适用。

## 6. 规律和联想

**星期几规律**（每晚，纯代码）：

- 取最近 56 天他说的陈述句（问句不算），按她的一天算（凌晨 03:30 前算前一天）；
- 切成 2–6 个字的小片段，去掉"今天""好累"这种谁都说的词；
- 门槛：至少出现在 3 个不同的周，并且至少 75% 落在同一个星期几。同一组日子只留最长的片段，配一句他的原话当例子；
- 存进关系账，状态"还在"；那个星期几他来聊了、却连续 3 次没提，标"停了"；
- 只在当天、或者他说"一般 / 每周 / 平时"时才给她看；**不会**写成"已确认"的看法（那样就收不回来了）。

**他几点来：** 每天取第一条消息的钟点，比较最近 14 个聊过的日子和之前 14 个，至少 5 天才出那一行。

**联想**靠四样：约定的触发词；底牌上的"（他这句话提到了）"加过敏原扩展表；同标签旧事带上结果；提示词一句"想起的里有相关的旧事，可以顺口提一句"。

## 7. 花多少

- 每轮：调用次数不变。提示词多 200–400 字（"今天"那节约 80 字，规律最多 100 字，翻摘要只在约 13% 的轮次多最多 320 字）。
- 收尾：次数不变，输入最多多 8 条消息。
- 夜里：次数不变，回想的提示词多约 300 字。
- 搬数据：0 次调用。
- bge（可选）：本地跑，约 60MB，不用 torch。算向量的代码放 `brain/`，记忆层只存数字（记忆层自己从不调模型）。

## 8. 搬她的真实数据（要你批准，§11 第 3 件）

一个脚本 `scripts/migrate_v3.py`。默认只预演；先备份成 `data/fish.db.bak-v2`；输出只在终端看，不写进仓库；永远不删记录。

1. 加新列，可以重复跑；
2. 给已经作废的旧条补"为什么"：在新条的合并来源里 → 合并；被同类新条顶掉 → 超了上限；其余 → 更新；
3. 合并出来、档是空的：沿合并来源往回找，取最重要的；来源全是待印证就恢复成待印证；
4. 她自己的事被改成"他……"的、"他一直没问成他"这种：列出来，**你确认后**只把开头的"他"换成"我"；
5. 补发生日：收尾写的那批，改用那次聊天最后一条消息的日子；
6. 用认承诺、认外号的规则扫一遍活着的条目，候选列给**你确认**后才设成约定；
7. 现在的"没问成"事件，牢固度改成最多 14 天（§4 批了的话，路过和待印证的上限一起套）；
8. 开着的惦记补上"从哪条记忆来"；
9. 补每次聊天的标签；先数一次规律。

搬完在副本上用 `recall_bench.py` 比前后。

## 9. 故意不做的

- **新建承诺表、日历表、规律表、向量表：** 约定用两列就够，规律用现成的关系账。这样记忆层代码不会翻倍，搬数据也简单。
