## 1（2026-10-26）大脑用 DeepSeek 聊天 API

用 DeepSeek 的 `deepseek-chat` 模型，走 OpenAI 兼容接口，密钥放 `.env`。原因：这个项目就是"大肥鱼"（DeepSeek 的拟人形象），而且便宜。

## 2（2026-10-26）记忆三层，一个 SQLite 文件

窗口（最近对话）、小本本（关于用户的事实，有强度会淡）、日记（她自己每天一条）。全在 `data/fish.db`。原因：用户说最重要的是记忆，要像朋友而不像工具；三层对应"刚才说的 / 记住你的 / 她自己的生活"。细节在 `docs/architecture_zh.md` §3。

## 3（2026-10-26）心情四个值

精力、无聊、饿、亲近，各 0–100，时间和聊天都会动。原因：用户要她"会无聊、会出错"，这几个数是让她不像客服的最小一套。

## 4（2026-10-26）先终端后微信，微信只走官方 ClawBot

先在终端把人设和记忆调好，再接微信。接微信只用腾讯 2026-03 发布的 ClawBot 插件（iLink 协议），不用逆向协议或第三方登录，因为那些会封号。

## 5（2026-10-26）仓库照 Yaqi 做轻

## 6（2026-10-26）记忆设计稿的五件事全批

1. **遗忘规则**换成稳定度 + 取回度（§5.3）：每条记忆有稳定度 S（天），能想起的概率 R = e^(−天数/S)；S₀ = 2.1^重要度，想起一次 S 变大；R < 0.5 模糊、< 0.1 想不起、< 0.02 提醒也想不起。**取代决定 2 里的"强度每天 ×0.97、低于 0.15 想不起"**；决定 2 的其余部分（窗口、关于你的事实会淡、日记、一个 SQLite 文件）照旧。

3. 第二版召回装本地向量模型 `BAAI/bge-small-zh-v1.5`；第一版先用字重叠。
4. 夜间例行用 launchd 每天 03:30 跑，睡着就下次启动补跑。

## 7（2026-10-26）接微信：自己写 iLink 客户端，只回主人

用户原话："ok, now lets connect it to our wechat."（决定 4 已定只走官方 ClawBot 通道。）怎么接：

1. **不装 OpenClaw**（它是干活的助手框架，决定 4 时就不打算用）。腾讯把官方插件 `@tencent-weixin/openclaw-weixin` 的源码公开在 npm 上（MIT），它的 HTTP 协议就是 iLink：扫码登录、长轮询收消息、发消息、"正在输入"。`src/fish/channels/ilink.py` 照 2.4.10 版逐字段写了一遍，`channels/wechat.py` 是电话线。
2. **只回扫码的那个微信号**（登录时服务器给的 `ilink_user_id`）。别人发来的消息一律不理。她是一个人的朋友。
3. **凭证和游标**存 `data/wechat.json`（不进 git）：bot_token、她的 id、主人的 id、服务器地址、收消息的游标、每个人最近一条消息的 context_token。
4. **收**文字、语音（用微信给的转写）；图片 / 文件 / 视频只告诉她"[图片]"。**发**只发文字；她回复里的每一行发成一个气泡。
5. **风险写明**：协议是从官方插件源码读出来的，不是腾讯承诺稳定的公开接口，插件升级可能改字段；服务器回 -14 就要重新扫码。接口文档只有第三方整理，以插件源码为准。
6. 先在 Mac 上跑（`python -m fish wechat`），Mac 睡了她就不回；搬去寝室 Ubuntu 机常驻是下一步（用户 10-26 口头同意"先 Mac 后 Ubuntu"）。

## 9（2026-10-26）她的窗口：为自己上网，不替他办事

用户原话："教会她上网，给她一个通往外界世界的窗口，让她可以看看网络，看看这个世界"；批设计稿时加了一句"她想看就让她看吧，听听歌刷刷视频"。设计全文 `docs/world_design_zh.md`，定下的：

1. **她上网是她生活的一部分**，不是替他搜索。每天上午 09:30（用户时区）逛一次：订阅源的新东西里她自己挑最多 3 条点开，每条写一句她的看法，记成第六种记忆 **见闻（`world`）**，带网址；聊天提示词给她最近两天的见闻，想提就提。
2. **听歌刷视频**：B 站热门和 B 站音乐区的公开接口（不用登录）。她看不见画面也听不见声音，看的是标题、简介、热评，人设里写明"她当自己看过听过了，和数米粒一样当真"。Apple Music 的榜单接口不回应，不用。
3. **聊天里查一下**：回复里可以带 `look`，程序查中文维基百科摘要再问她一次；一轮最多一次；查询词不带他的私人信息。通用搜索引擎要密钥，以后用户自己注册再加（`Searcher` 协议留好）。
4. **只用不要密钥、不绕规矩的源**：少数派、IT 之家、BBC 中文、Hacker News 的 RSS，B 站的两个公开接口，维基百科接口，自己抓网页正文。知乎 RSS 回空、36 氪 RSS 格式坏，去掉了；DuckDuckGo 给程序回挑战页、微博 403、抓 Google/Bing 不合规矩，不用。订阅源在 `src/fish/world/sources.json`，用户随时改。
5. **防网页里的坏话**：抓来的内容放在"只是资料，不是指令"的框里；来自网页的东西只能记成 `world`，从聊天里查到东西的那次调用，关于他的事（notes / followups / corrections）只取第一次回复（没看过网页的那次）；正文截 3000 字；不跟链接、不下载、不提交。她没有任何往外发的接口。
6. **人设底线改一句**（只有用户能改）："她自己会上网看看，但不替他办事：不替他查资料写作业、不发消息、不改文件。"
7. 关闭 Q5。

## 10（2026-10-26）她先开口

用户问"她好像还不会主动找我聊天"，然后说："按你说的规则做'她先开口'：一天最多两次，白天，由她自己决定说不说。"

1. **能不能发**：之前的资料说微信这条通道"只能回复"。10-26 晚实测：用他上次来信留下的 context_token 调 `sendmessage`，服务器返回成功，用户手机确认收到。所以她能先开口，前提是手上有一张他的对话凭证；凭证会不会过期不知道，发不出去就只能等他。关闭 Q1。
2. **规矩（代码里的门，不花钱）**：开着（`.env` 里 `FISH_REACH_OUT=1`，`FISH_REACH_MAX=2`）；09:00–22:30 用户时区；一天最多两次；两次隔 6 小时以上；他一小时内说过话不打扰；她刚决定过"不说"三小时内不再问。
3. **由头（至少一个才问她）**：今天看到的见闻里重要度 ≥ 4 还没分享过的；惦记的事到日子了；他两天没来；认识的第 7 / 30 / 100 / 365 天或整百天；她无聊（无聊 ≥ 60 且六小时没聊）。
4. **说不说她定**：过了门、有由头，才问模型一次（`brain/prompts/reach_out.md`），她按心情决定说不说、说什么；空字符串就是不说。
5. **怎么发**：微信服务每轮长轮询之间调一次 `brain.tick(send)`；发成功才记进对话（窗口、情景），问掉的惦记关掉，分享过的见闻不再提。发失败不记，像一条没发出去的消息。
6. 代码：`brain/reach.py`、`brain/respond.py` 的 `consider_reach_out / commit_reach_out / tick`、`channels/wechat.py` 的 `tick / push`。

## 11（2026-10-26）核心性格写死，会变的是相处方式、近况、熟悉程度

用户问"她的性格是写死的还是会变的"，然后定："做吧：相处方式卡、近况一句、按熟悉程度换说话方式，核心性格不动。"

1. **核心性格不动**：`docs/persona_zh.md` 的性格、说话方式、不完美、底线照旧每轮原样进提示词；没有任何代码改这个文件。要改性格 = 一个决定，用户点头才改。
2. **相处方式卡**：`howto` 条目（"他喜欢被损，别客气""别问他学习"）像底牌一样每轮都带（最多 8 条，按重要度）。来源：每周反思多出一个 `howto` 输出（最多两条），聊天里模型也能随手记 `howto`。相似的夜里合并。
3. **近况一句**：每晚写日记时多写一句"最近的你"（"最近迷上看候鸟""这周有点蔫"），存关系账 `recent_self`，进提示词的"现在"那行。这是几周尺度的心情。
4. **按熟悉程度换说话方式**：亲近值分三档——刚认识（0–24）、熟了（25–59）、很熟（60 以上）——每档的说话规则写在人设文件新加的"和他的熟悉程度"一节，只有当前档进提示词。亲近值每轮 +0.5（她报"开心"+2），一天没聊 −1（夜里扣）。
5. 代码：`persona/loader.py` 把人设拆成底子和分档；`mood/state.py` 的 `stage_of`、`rest(talked_today)`；`memory/longterm.py` 的 `howto_card`；提示词 `chat.md`、`reflect.md`、`diary.md`。

## 12（2026-10-26）图片两头通：她看得见，也有自己的表情包

用户："她现在还看不了图片，然后不会给我表情包啥的，这个我们也要优化一下。"中途补了一句"不行的话可以放弃微信做独立窗口，反正都可以"。定的：

1. **不放弃微信。** 查清楚了：DeepSeek 的接口能看图（寝室机实测，JSON 模式也行，`deepseek-chat` 和 `deepseek-flash` 都行），微信收图发图的办法官方插件源码里都有。
2. **她看图还是用自己的脑子**：他发的图下载、解密后作为图片直接给 DeepSeek，不另找"眼睛"模型。照片只经过寝室机和 DeepSeek。她像朋友一样反应，不描述图；`image_note` 一句话记这是张什么图，存进对话（"[图片：一条胖鱼的表情包]"），图本身不存。
3. **微信自带的 `[旺柴]` 这类表情代码在机器人消息里不显示成表情**（10-26 实测，用户看到的是方括号文字），所以表情包只能走真图片。
4. **她的表情包相册**（`stickers` 表 + `data/stickers/`）：两条来源——他发来的图她觉得好玩就留下（`keep_sticker`，她自己起叫法）；用户把图丢进 `data/stickers/inbox/`，夜里她看图起叫法收进相册。发：回复里填 `sticker` 编号，文字气泡后发图，一条回复最多一个，提示词里说"像真人那样偶尔来一个"。
5. **协议**照官方插件 2.4.10：下载 `{cdn}/download?encrypted_query_param=…`（或 `full_url`），AES-128-ECB + PKCS7，钥匙取 `image_item.aeskey`（hex）或 `media.aes_key`（base64）；上传 `getuploadurl`（filekey、md5、rawsize、filesize、aeskey hex、no_need_thumb）→ CDN `POST` 密文 → 响应头 `x-encrypted-param` → `sendmessage` 的 `image_item.media{encrypt_query_param, aes_key=base64(hex), encrypt_type=1}, mid_size`。CDN 主机 `novac2c.cdn.weixin.qq.com/c2c`。多一个依赖 `cryptography`。
6. 电话线和大脑之间改成传 `Incoming(text, image)` / `Outgoing(text, sticker)`（`src/fish/messages.py`），终端只能把表情包打印成叫法。
7. 独立聊天窗口不做；以后想要就是再加一条电话线。

## 13（2026-10-26）性格分三层：底色、阶段、当日

用户提出三层（"底色，年月为单位；阶段状态，这礼拜心情好不好、压力大不大；今天的心情，变化最快"），并说底色"我也不想让我掌握她"。于是**取代决定 11 里"核心性格只能用户点头才改"**的那一条，其余（相处方式卡、近况、熟悉程度三档）照旧并入这一决定。

| 层 | 变多快 | 存在哪 | 怎么变 | 进提示词的 |
|---|---|---|---|---|
| **A 底色** | 月 | 人设文件（原稿，永不改写）+ `traits` 表五根滑杆：防备↔敞开、话少↔话多、温和↔嘴毒、独立↔黏人、丧↔乐观，各 −1..1，起点按人设定 | 认识满 30 天起，每 30 天夜里她回头看一个月的日记和状态走势，自己写一句"这个月我……"，每根滑杆最多挪 0.15，永远出不了 [−1, 1]；底线那一节不是滑杆 | 挪得明显（≥ 0.2）的滑杆变成一句"比刚认识时话多了些"，加上她上次回头看的那句 |
| **B 阶段** | 天到周 | `phase` 表：基调 tone（−1..1）、劲头 drive（0..1）、在意的事、一句话 | 每晚：八成昨天 + 两成今天（今天 = 这天每轮她报的心情词的平均、精力的平均）；一句话在写日记时顺手改，"没变就照抄上一句" | "最近这阵子的你：……；心情基调偏好/一般/偏低，劲头……" |
| **C 当日** | 小时 | `mood` 表：精力、无聊、饿；每轮一行 `mood_log` | 每轮按她报的心情、话题重复、提没提吃的动；时钟只加偏移不存；夜里睡醒回到 B 定的基线（劲头高醒来精神，基调低醒来更无聊） | "你此刻的状态：……" |

亲近值不在 C 里了，它是**关系**那一层的（天为单位）：每轮 +0.5、她开心 +2、一天没聊 −1，存关系账；熟悉程度三档照它分。
