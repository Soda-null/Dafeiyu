# `evals/`：记忆体检的剧本和结果

> **是什么：** 逐步喂、隔久再问的评测（决定 18，`docs/checkup_design_zh.md`）：剧本在这，跑出来的报告也在这。
> **地位：** 索引。新剧本在这加一行；结果文件按日期和版本命名，不改旧的。
> **读法：** 看 `results/` 里最新的两份比。

| 文件 | 是什么 |
|---|---|
| `xiaozhou_90d.json` | 小周的 90 天：一个编出来的大二机械系朋友。埋了七类事（一辈子 / 本人 / 日常 / 路过 / 改口 / 规律 / 不能记），分"被提过"和"没再提"两组；时点 1 / 7 / 30 / 90 / 365 天。剧本里的"filler"是没埋东西的日子轮着用的二十段闲聊。**现在是剧本第 2 版**（2026-10-27）：承诺题改用"海边 / 看海 / 海的照片"认答案（原来的"海"会认到去上海那条），挑闲聊的步长 5 → 7（原来 20 段只用到 4 段）。闲聊变了，第 2 版的成绩不能和以前的直接比，`results/` 里 10-27 那几份都是第 1 版 |
| `xiaolin_60d.json` | 小林的 60 天（最后一轮拨到第 180 天）：第二个编出来的朋友，刚毕业在 Springfield 做 UI 设计。专考名字像的两个人（阿杰 / 杰哥）、口味改了又改回来、"下下周二"、一件事分两条消息说、伤心事不能编结局、他主动让她记门锁密码（不该记）。记忆第三版设计时看过它，只算半个没见过的考卷（`docs/memory_v3_zh.md` §10） |
| `results/<日期>-<版本>-<天数>d.md` | 一次体检的报告：总分（硬线、格子、顺带想起）、分数表、每一问的原话和裁判理由、她最后记得什么 |
| `results/<日期>-<版本>-<天数>d.json` | 同一次的机器可读版，给以后并排比；她的每句回答都在，所以裁判规则改了可以 `--rejudge` 重打分不重跑 |
| `results/…-rejudged.md / .json` | 重打分后的版本；有它就看它，不看原来的 |

跑：`.venv/bin/python scripts/checkup.py evals/xiaozhou_90d.json --label v1`（完整，约一千次调用，一两个小时，花钱）；调参时 `--days 30 --no-final`。在临时目录里跑，从不碰 `data/`。

跑完不花钱再看两样（库是体检开头打出来的临时目录里的 `fish.db`，跑完不删）：`scripts/recall_bench.py <库> <剧本>` 看答案有没有摆到她面前，`scripts/write_coverage.py <库> <剧本>` 看每件事写到了哪一层（笔记 / 摘要 / 只在原话）。

剧本里的人和事都是编的。不要把真人的聊天放进来。
