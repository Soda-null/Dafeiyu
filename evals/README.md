# `evals/`：记忆体检的剧本和结果

> **是什么：** 逐步喂、隔久再问的评测（决定 18，`docs/checkup_design_zh.md`）：剧本在这，跑出来的报告也在这。
> **地位：** 索引。新剧本在这加一行；结果文件按日期和版本命名，不改旧的。
> **读法：** 看 `results/` 里最新的两份比。

| 文件 | 是什么 |
|---|---|
| `xiaozhou_90d.json` | 小周的 90 天：一个编出来的大二机械系朋友。埋了七类事（一辈子 / 本人 / 日常 / 路过 / 改口 / 规律 / 不能记），分"被提过"和"没再提"两组；时点 1 / 7 / 30 / 90 / 365 天。剧本里的"filler"是没埋东西的日子轮着用的二十段闲聊 |
| `results/<日期>-<版本>-<天数>d.md` | 一次体检的报告：总分（硬线、格子、顺带想起）、分数表、每一问的原话和裁判理由、她最后记得什么 |
| `results/<日期>-<版本>-<天数>d.json` | 同一次的机器可读版，给以后并排比 |

跑：`.venv/bin/python scripts/checkup.py evals/xiaozhou_90d.json --label v1`（完整，约一千次调用，一两个小时）；调参时 `--days 30 --no-final`。在临时目录里跑，从不碰 `data/`。

剧本里的人和事都是编的。不要把真人的聊天放进来。
